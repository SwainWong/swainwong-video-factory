# SwainWong视频制作流程

按当前用户简报制作可观看、可编辑、可追溯的视频。先把研究和完整视频脚本做到可生产，再尽快形成整片 First Full Cut；后续在同一完整时间线上横向替换素材、补动画／声音并验收，不逐段做到成片级才开始下一段。用户最新要求优先；人类原始素材受保护，修订和清理按本期授权及引用关系执行；制作授权不等于公开发布授权。本规范版本：4.9，作为 `swainwong-video-factory` Codex 插件的唯一公开 Skill，包含可执行状态门槛、插件级分镜机器门禁、逐句画面语义合同、direct-evidence 实开 capture receipt、两级素材覆盖率实测、主画面与事实叠加层双重同源去重、最终字幕像素证明、A-roll、初始制作条件锁定、多动效库风格接入、渲染后逐帧/片段反馈、候选片视听准入、最终像素与来源质量门禁、动画音效配套合同及十二岗位内部 Harness。

## 执行约束与持续反馈

以 [Harness 主入口](harness/HARNESS.md) 路由一定要做、推荐做、一定不能做、验收与失败处理四类清单；按当前阶段读取适用规则及原合同，不把推荐升级为硬门槛。审片页提交后，读取[反馈到 Harness 的沉淀合同](references/harness-feedback.md)，核对不可变快照、实际截图或片段，逐条解析并用工具写回处理结果。已有规则优先引用；新经验持续进入四类候选目录，候选不等于生效规则。独立审核和用户对具体条款及范围的明确确认后才纳入长期规则；“仅返修，不沉淀”必须尊重。此链路不自动修改 Codex 记忆。

新片或重编先读取[可执行工作流状态合同](references/workflow-state-contract.md)与[运行依赖](references/runtime-requirements.md)，先运行 `scripts/preflight.py`，再通过 `scripts/workflow_state.py` 锁定简报、生成岗位任务包和记录产物。凡是依赖、哈希、文件和状态能机械判断的项目，以该工具结果为准；不得用 Prompt 自报绕过。故事、画面、表演、声音与审美仍由对应角色实际判断，工具 `READY` 不等于创作验收。

写稿与首次整片粗剪读取[First Full Cut 合同](references/first-full-cut.md)及[定稿式口播与短语级双语字幕合同](references/editorial-style-and-subtitles.md)。完整、可朗读、事实有界且经过编导／事实审核的 `PRODUCTION_READY_SCRIPT` 是 First Full Cut 硬前置；口播必须呈现已经想清楚的最终表达，不能把研究、推理、自问自答和反复叠甲当成成稿。最终素材、精细动画、SFX、BGM 和成片级混音不是粗剪前置。最低完整播放条件一成立就立即交付整片粗剪，不设固定一小时门槛，不以局部精修阻塞整片存在。最终音频锁定后，双语字幕按短语切分为一一对应 cue，不得退回整句长块。

完整成片候选进入最终关口前，读取[候选片视听准入门禁](references/candidate-av-gate.md)。`editing-final` 只产出绑定最终像素机器门禁的候选；随后三份 G3 独立审核绑定同一候选哈希，`candidate-internal-gate` 汇总正常速度完整看听与机器门禁，全部通过后才生成 `owner-review-ready`。同一候选必须锁定允许／禁止素材类型与唯一字幕渲染权威，并由正常速度完整看听分别确认视觉素材政策、单一字幕、口播节奏、动画SFX可辨和BGM可闻；轨道、cue、响度、哈希或测试渲染 override 均不能替代。First Full Cut 只执行独立的完整性合同，不冒充最终视听通过。

派子 Agent 前读取[内部岗位方法与 Harness 索引](roles/INDEX.md)。十二个岗位是本 Skill 的内部角色模块，不是与主 workflow 平级的可发现 Skill；不得要求用户用岗位名直接调用。主 Agent 把对应 `METHOD.md`、`HARNESS.md`、同版简报、上游产物、适用规则 ID、期望交付与证据一起交给子 Agent；子 Agent 只对自己的职责和产物签署状态，不能把岗位 `READY` 扩成全片通过。用户明确要求由独立 Codex 制作对话执行时，主对话只维护简报、状态、任务包、门禁、验收与汇报；脚本、字幕、工程和渲染等生产写入只能由绑定的持久制作对话完成。主对话可修插件和检查证据，但不得越过边界亲自替制作对话改片。

## 开始时

每个新制作任务（含新一轮成片重编）先读取[初始制作简报与锁定合同](references/production-brief.md)。人类须确定主题与核心表达方向、目标观众/目的、画幅、目标时长及上下容差或明确范围、口播语言与音色、字幕语言，以及平台、Logo、A-roll、预算、清理与交付条件。核心方向可以是中立问题或待验证假设，不必预设结论。口播语言与字幕语言分别记录；真人原声不强制VoiceStudio。

用户已给的答案直接沿用，默认值先可见再接受，可一次确认整份简报，不逐项重复追问。主Agent只收发输入、校验结果与派单；字段/范围/条件必填由校验工具检查。缺项、未确认或必要档案待核验时不派后续研究、动画匹配或生产；入口准备可展示库存和核验能力。保存表单不等于锁定或已派单，`brief_confirmed=true`须对应真实人类确认。只有当前版本初始关口通过，才派后续岗位；所有任务绑定相同简报版本/哈希。

平台选择为**OpenFilm、ChatCut、两者都做**。不能从上次工程推断本次选择；双平台遵循同一锁定脚本并分别维护制作、渲染与验收，主Agent不假扮平台制作或独立审核。仅讨论流程、复盘或改规范不需要启动新片的完整表单。条件改动须人类确认新版本并标记受影响下游失效；事实冲突回传证据调整方向，不为已锁定观点保留错误事实。

选择口播或仅改口播文案/朗读时，加载[口语与表演配置](references/speech-style.md)。每次启动口播制作、以及改变节奏方案后，生成前必须主动说明采用**匀速清晰**还是**自然起伏（模拟真人表达节奏）**，简述理由及具体快/慢/停位置；沿用设置也要明示。分别提供**叠甲强度、口癖强度、语气起伏、局部语速变化**，不能用一个“真人感”开关代替。叠甲与口癖默认轻量；已选设置沿用，初始简报展示并获接受的默认可直接执行，不逐项强迫确认。后续专业岗可在已锁定意图内设计具体快慢停位置，但不能静默改动已锁定条件。仅做纯音频试版时不新建视频工程，也不追问剪辑平台。

阅读[制作与验收规范](references/production-standard.md)；写脚本/分镜时阅读[叙事、动作与声音设计合同](references/storyboard-contract.md)；派审核Agent前阅读[独立审核门槛](references/review-gates.md)。只在平台选定后加载OpenFilm或ChatCut相应技能。维护brief、facts、script、shotlist、动作/声音表、assets/sources、review及交付清单，不把本集人物和配乐当作永久默认。

选配音或扩充声音时阅读[音色发现与选择](references/voice-selection.md)：以本地VoiceStudio实际库存为主、已核实免费ChatCut音色为补充，首屏目标10个独立可试听音色并支持加载更多；不足就如实列出，不用别名或未生成模板凑数。已有明确选音沿用，不强迫重选。规范定义流程，不代表连接器、界面或音色已安装可用。

## A-roll 主持画面

用户需要真人录制、HeyGen等数字人口播、左人右内容或人物小窗时，读取[A-roll获取、剪辑与验收合同](references/a-roll.md)。在人类配置入口开放来源、人物、音频模式、布局和出镜范围；skill默认值可覆盖。真人录制使用实测原声，不强迫选择VoiceStudio；数字人明确使用已批准音频驱动或平台声音生成，不擅自换声。

岗位扩展为1主Agent＋12个子Agent职责：保留①–⑪编号，新增独立⑫BGM Agent，按任务范围和依赖调度，不要求同时运行。主Agent承接输入、派单、依赖和报告，不兼任生产或审核；A-roll由②文案、③分镜、④口播音频、⑤素材、⑥动画与动效音效、⑦剪辑混音、⑧交付、⑨⑩⑪独立审核及⑫BGM协作。按句子ID、take manifest和源/时间轴时码交接；真人原声或数字人实测音频决定后续同步。DataMagic配方须先查实际视频能力，不支持时由OpenFilm/ChatCut剪辑层承载真实A-roll，图表层继续播放。

以下第三方纯素材3–5秒、同源唯一性、8:2规则限定于被引用的第三方证据/B-roll，不适用于已授权主持A-roll。主持同源不同有效句段及全屏/分屏/PiP容器可复用，不能循环口型或冻结讲话凑时长；小窗下的第三方素材和整镜图表仍照常查重。A-roll单列比例与覆盖。G1制作前、G2 First Full Cut 定整片问题、G3最终验收均由独立审核岗参与，检查声画同步、裁脸、字幕/Logo/进度条/数据遮挡以及数字人失真；不通过返修后复审。

## 可选开头模式

用户希望从正文各段提炼一个或多个爆点，以“大文字＋前景主体”动画组成开头时，采用 [H01 爆点预告式开头](references/explainer-motion/highlight-hook-opening.md)；未指定时按内容评估，不默认每片使用。先有完整正文，再提炼、排序与建立正文兑现关系；每个爆点按口播关键词分次揭示。视觉复用已有 D01 字体与层级动画，H01 内允许有限包装复用，边界见配方；不固定 18 秒、爆点数量或案例配色，也不放宽素材去重和视听验收。按 H01／D01 的 2026-10-30 修订落实饱满前景、突出大字与真实遮挡；基线可直可曲、样式统一。阅读在主构图内完成，去掉无语义的末段拉平上移闪换，并统筹相邻主题整场切换及正文接入；曲线适配不冒称通用字体 API 已支持。

## 讲解动画补充能力

口播章节开头优先评估 [D01 主体遮挡章节标题](references/explainer-motion/foreground-depth-title.md)：人物、车辆、建筑或其他主体置于完整大标题前方，支持图片与同步视频遮罩、可配置字体字号及 10 种进入／出现动画；制作前按 [D01 对外接口合同](references/explainer-motion/foreground-depth-title-interface.md)设置真实字体样式、颜色、间距、阴影／描边及 cues 时序。章节开头编辑选型相对权重建议为 3.0（普通候选 1.0），语义、可读性和可分割性先行；这是推荐偏好，不是自动评分器或必用配额。按该配方的窄范围章节包装复用例外执行，普通整镜模板和第三方同源素材仍不得重复。

制作或改编动画时读取[动画与音效配套合同](references/animation-sound-design.md)，以下是本轮对话确认的统一配置要求：

- **职责**：⑥动画Agent负责画面、运动及对应SFX，交实际带声预览和独立可编辑SFX；⑫BGM Agent负责跨镜头、段落和全片配乐；⑦负责组装混音。
- **分类与选材**：按“画面事件识别→动作分组→声音角色分类→授权素材库检索→对齐与试听混音”执行。纸张、信息揭示、数据、关系延伸、机械接触、结论强调按作用选声；不以同一声音或相近噪声覆盖所有动画。综艺式表现力服务于叙事和节奏，不能等同于增加提示次数。
- **发声单位**：同一动画的多帧、补间、表格密集展开或连续移动共用一个动作组，开头、重点或结束选一次短提示，或用一个完整连续声体。所有事件保留组级处置，组内不重触发不算漏配；禁止多个短音拼接/堆积冒充长声，预混成单文件也不豁免。
- **再次触发**：独立新故事或真正的新动作可另配声；2–3秒仅作可调检查范围，2.5秒是已试项目的编辑初值，不是通用最佳间隔。相同动作持续多久都不因到点重响，被抑制的状态也不排队补播。
- **混音与验收**：同时核新SFX和原工程已有音效，避免同组双配或静态画面残留装饰提示；动作改变后重对齐。保留无BGM同步预览、独立轨和来源/分组清单，实际听审材质、重复感、同步及旁白清晰度；cue数量、覆盖率和响度检查不能代替听感验收。


从DataMagic或第三方GitHub动效库选配方、改编或跨库组合时，先读[多动效库统一风格与接入合同](references/motion-library-adapters.md)：一套全片CI与共用资产、逐配方能力映射、运行时/编辑器交接、总包装单次渲染及分级证据。统一prompt不是通用API，源码核查不等于已渲染或接入；现有A-roll例外、唯一性与仅DataMagic延时例外保持原范围。

这些讲解动画不是商业分析专属。只要内容涉及关键数值、数量比较、占比、并列结论、关键词强调、案例切换或复杂关系，或用户点名动画效果，商业分析、科技原理、产品评测、历史/教育论证、品牌与人物故事都按需阅读[讲解动画索引](references/explainer-motion/index.md)，再读取选中的配方。Agent按内容、阅读时间和当前视觉风格选择，可以不用，不要求每条视频集齐效果；用户点名则优先满足，有数据或语义冲突时说明并调整。

当脚本涉及多方人物/公司或机构关系、因果机制、报价/参数、来源证据、资金流或第三方视频画面时，继续读取[关系驱动商业讲解案例](references/explainer-motion/case-bv1fcps68egf.md)；这里的案例可迁移到科技、产品、历史、教育和人物故事，不要求主题本身是商业分析。将口播意群标成身份、证据、关系、比较、计算、机制、情绪反差或结论，再按“对象→关系→数值/状态→结论”揭示；第三方画面按 `claimRole` 选择并记录来源、权利、原声和回收点，不把参考片风格或素材固化为默认。

当项目提供本地参考图片/视频目录时，读取[本地参考包配方](references/explainer-motion/reference-datagram-20261014.md)。先完成“观察→配方→工程接入”的沉淀，再应用到项目；至少记录素材状态、可复建动作、固定叠加层、数据口径和验收证据。第三方素材默认使用 `rights_status=reference_only`、`usable_in_edit=false`；但若用户明确确认其在当前地区/项目范围内可以引用，则按用户确认范围登记 `rights_status=authorized`、`authorization_basis=user_confirmed_authorized`、`usable_in_edit=true`，并保留原始 URL、来源 ID、使用区间和语义角色。该项目覆盖只适用于用户确认的范围，不自动声称已取得公开发布、商业再分发或其他项目的授权。

配色、字体、材质、画幅与时长跟随当前制作简报和已确认的项目风格；10秒demo的浅粉/珊瑚红、网格、演示数字和全屏构图均非永久默认。纸艺视频复用信息揭示逻辑并适配纸艺材质，不能把光滑矢量当作纸艺；用户明确选择信息图风格时可使用矢量图表。此模块补充视觉表达，不改变既有脚本、事实、声音、审核与交付规范。


## CI、素材比例与引用的当前标准

制作前读取[CI与素材节奏合同](references/ci-and-media-standard.md)。为全片先锁一套可编辑CI：主题配色、中文标题/正文、展示数字、引用/代码字体、Logo与字幕安全区、纸艺材质和动效速度；所有页面与第三方动画适配这套token，不逐镜随意选色换字体。关键数字用有辨识度的展示字形与层次设计，不能只把正文字号放大。

第三方素材主画面与原创动画默认8:2，并列出统计分母及混合镜头，不能把被遮满的背景算成第三方主画面。纯素材3–5秒，DataMagic实质叠加可延至讲解完成。品牌名称旁使用对应真实Logo；多角色名称旁使用可辨识的纸艺卡通/照片裁片；食品和人物避免简陋几何矢量。按用户确认的授权范围，高斯模糊第三方平台/作者水印，并把真实出处统一迁到左下；保留原始文件，实体招牌不误作平台水印。

第三方素材内部，图片:实拍视频尽量达到3:7；默认按实际主画面时长统计，同时列独立素材数量，图片推拉或转成MP4仍算图片。满屏适配、贴顶通栏半透明分段进度条、右下SwainTalk Logo按CI合同执行。地理、人物/品牌、门店和机制镜头读取[对象、关系与观众理解](references/visual-semantics.md)：对象形象化、标签居中加粗、Logo归属清楚，矢量信息不相互遮挡。

法规、社媒原文、文档或代码引用优先使用[Barty-Bart/motion-graphics](https://github.com/Barty-Bart/motion-graphics)的相应动作方法：先核真实原文，再做卡片展开、逐行显现、关键句高亮/代码输入；不编造账号、互动数或执行结果，不截断引文却假装完整。按需读取CI合同内的接入说明。

动物行走、跑跳、飞行或攀爬等身体动作，制作与审核时读取[动物动作可信度审查](references/animal-motion-review.md)：分别检查发力承重、关节姿态、接触、轨迹节奏和正常速度观感；静帧或程序数值通过不等于动作可信。

## 从故事到画面

选用 H01 时先读[爆点提炼与开头交接](references/explainer-motion/highlight-hook-opening.md)，从完整正文反向提炼开头，不先编悬念再强行补正文。

先明确“观众看完能回答什么”，选择一个核心矛盾；列出钩子、完整事件、转折、高潮与一个落点。履历为核心事件服务，幽默来自观察、自嘲和反差，不编事实、台词、亲历或人物心理。把故事提问登记为承诺与回收表：提出几个对象就交代几个，宣称发生调整就给出可核实的调整，不能靠总结词填补过程。

锁定全片逐镜视听脚本：原句/原声、观众问题与本镜答案、人物与阶段、场景、动作因果、资产状态、入出点/运动路径/层级/接触关系、来源及事实时间、声音主次、字幕槽。涉及形变的动作另列关键帧和帧区间；未定义的镜头不能边渲染边补。关键证据或承诺内容未找到，不得进入批量制作；调研、调整叙事范围或请求用户决定，不能悄悄删掉明确要求。

纯第三方视频/图片单次连续展示控制在3–5秒；背景上有实质DataMagic讲解动画时，可延长到该动画完成，需登记配方、语义步骤和结束点。固定标题、换字幕、循环装饰和缓慢推拉不构成延期理由。未被简报更严格限制时，完整原声另按已设计的完整句意处理；本轮3–5秒且仅DataMagic例外的规则优先，应另选长度适合的完整原句，不能借原声延长纯素材。切镜数量、30fps导出、抖动、推拉和换字幕不等于新信息或动画完成。优先保证动作、句意和反应完整，不把完整原声剁成碎片。

纸艺调用`paper-depth-storyboard`与内置imagegen。保留印刷网点、粗白边、纸厚、撕纸、层间阴影与浅景深；本流程的独立裁片、多状态、动态构图优先于它的整景生成、固定辅助元素上限和默认6秒。元素数量由语义决定，不限两件，也不机械堆满。先生成裁片/状态或动作组合，后期在稳定的前中后景组装，不让整个画面替代裁片动作。

实体必须第一眼对应口播：城市有当地地标，人物有参考特征，菜品/奖项/场合有真实依据；特定获奖事件优先生成“真实人物＋实际奖项＋对应持奖姿态”整体裁片，先核物件形制，不把奖牌臆改成杯状奖杯，也不用通用奖杯替代。高频主体按人生/事件阶段、情绪、目光、手部动作建立状态库；不循环两张立像。不能凭需要编造真实人物的愤怒、流泪或史实场景。

过程包含施力主体、接触、形变、结果。揉纸至少5–6个可辨形变状态，默认6个以上，优先手与纸同一组合连续生成；补中间态并在实际速度预览。完整姿态切片优先，不靠拆四肢旋转补表演。否定可用生成的撕纸红叉，贴到真正被否定的对象；禁用代码矢量红杆/方块冒充纸艺。代码可驱动已生成裁片的位置、缩放、遮挡与播放时间。

## 画面唯一性：硬性要求

**同一成片内，第三方视频/图片不得重复使用；DataMagic及其他讲解图表的一般相同表格、整镜模板和动画效果也不得重复套用（D01 章节包装及 H01 开头包装的有限复用范围见下文）。第二次使用即为不通过，不等第三次，也不以“回扣、换口播、有新解释、占比达标”豁免。** 写分镜、选择动画、剪辑和审片时必须读取[画面去重与口播对应](references/visual-uniqueness.md)，建立全片素材与效果唯一性台账。裁切、镜像、调色、换字幕、换数据、另存文件或换效果ID不能掩盖重复；素材不足就补充新素材或按语义设计新动画。固定Logo、字幕样式、章节导航及同一镜头内连续推进不属于重复主画面。[D01 章节标题包装](references/explainer-motion/foreground-depth-title.md)可在不同真实章节开头复用，每处须有不同原始素材、独立章节观点和合适阅读时间；选用 [H01 爆点预告式开头](references/explainer-motion/highlight-hook-opening.md)时，同一预告内多个爆点也可按其范围共享 D01 层级包装，以 opening_hook 登记而不虚构章节。两种例外均不放宽第三方同源重复或一般图表／整镜模板去重。

## 素材、声音和排版

第三方素材优先原始实拍、官方原片、纪录片和采访，避免强二创动画/浮动标题；综艺原生包装可保留。按事件覆盖调研，每个第三方原始视频只安排一个连续选段，每张原始图片只安排一次连续展示；不能从同源反复切片填全片。统计独立来源、原始内容、事件/阶段覆盖与唯一性结果，重复使用次数必须为零。赛后叙事优先赛后实拍；十年前的厨房即使标了年份，也不能拿来补当前赛后现场。

第三方视频/图片独占舞台时必须覆盖全画幅：优先等比放大并围绕焦点裁切；需保留完整内容时，使用同素材铺满的高斯模糊背景加清晰前景，不能居中后留纯色大边。允许按用户建议试验非等比拉伸，检查人物、文字、Logo及建筑比例，明显变形时改用模糊背景或替换素材；具体见CI合同。独立透明PNG优先；若图集，按每行实际轮廓和隔离带定边界，逐格验收邻格残片、透明边缘和动作配准，不机械平均切格。

VoiceStudio用用户选定且有使用依据的声音，本人克隆保留原样本/档案，不上传到未授权服务。先做30–45秒含叙述、包袱、转折和思考的表演试音，优先完整口语意群；记录实际支持并发送的参数，不能把文案中的mood当作引擎已执行。否决后先区分音色与节奏/重音问题；只需修节奏时不改声音档案，可用同参数10–20秒A/B诊断句式/标点，选定后仍需较长试音验收。按[口语与表演配置](references/speech-style.md)只在有语义目的的完整意群上做局部语速变化，随后恢复基准；不要逐词切碎、每句轮流变速或机械加静音冒充自然表演。引擎缺少重音/情绪控制时如实说明，不把语气词等同于整句情绪，不无意义重试、不擅换声音或安装付费引擎。

声音先设计三类段落：旁白主导、人物原声独占、现场环境声主导。给关键事件安排旁白退出窗口，保留完整短句、锅铲、呼吸和反应；BGM持续可闻并主动降低让位；用户要求贯穿时不得抽掉BGM；其他项目只有已明确设计的留白可例外，不以整段静音代替混音。不能默认所有实拍muted，也不能叠两个人声抢话；恢复原声前核实内容、语境和同步。

统一字幕、说明、引用、水印位置与安全区。口播与第三方原声字幕共用固定底部中央槽，单语白字、紧贴文字的黑底、最多两行向上扩展，不切换顶部槽。来源固定左下，SwainTalk Logo固定右下；直接使用透明Logo，不加半透明黑底或黑色容器；具体默认值及冲突处理见制作规范。锁定后不逐镜漂移，主体/字幕冲突应改构图或素材。说明和来源用克制小字，不重复标题/字幕；顶部使用贴顶通栏半透明分段进度条，所有章节（包括开头和结尾）均用对应口播观点浓缩出的词或短语命名，不用“开篇／总结”通用标签，不得直接写“观点1／观点2”等编号占位；章节宽度按实际时长占比，玫红亮色随全片播放时间从左向右线性累积填充，越过真实口播章节边界而不整段跳亮或逐镜归零；去掉左上常驻小章节/论点标题。不另加页码、计数器或PPT式章号，章节条用语义标题，不用观点编号。内容确需的年份、数量可显示。

用透明SwainTalk Logo作固定右下水印，主题动作片头和可读致谢片尾强化IP。**不常驻“AI纸艺示意”“原创概念示意”“Business Notes”等冗余标记**；通用概念/历史备注合并为片尾一句，关键数字的年份、分母与实际引用上下文仍保留；来源与生成记录留内部台账。必要的年份/事件说明仍保留；不伪造历史影像、采访或背书。平台确需的合成内容披露按发布规则单独处理，不自动每镜加标或强制加AI片尾卡。片尾列第三方来源、作者、音乐与致谢。

版权按模式处理：交互模式在方案阶段集中提出疑问；用户已确认的授权按其范围登记为user_confirmed_authorized并继续，不反复追问也不冒称独立查验证书。一次性模式可先将有疑问的可正常访问素材用于本地制作，台账保留待核状态，交付集中补充疑问与使用区间；不默认全部licensed，不绕过DRM/付费墙，不代替公开发布授权。

## 审核与交付

研究后先完成可生产脚本；专业编导与事实检查独立审核脚本同一版本，关闭 Critical／Important 后进入粗分镜。视觉语义岗检查粗分镜，但不得阻塞已经具备最低完整播放条件的 First Full Cut。First Full Cut 出现后，编导、视觉语义和事实岗在同一完整时间线上并行检查结构、误读、缺口和风险；正式配音、素材、BGM 与后续动画准备同时推进。修改后只复审受影响处；旧版 PASS 不继承为新版 PASS。工具不可用则如实标记，不由主 Agent 冒充独立审核。

First Full Cut 可以包含明确登记的临时画面和未完成项，但必须完整可播、目标时长成立并绑定可生产脚本。高风险技术小样只在确有未知项时并行验证，不是整片开工许可证。完整候选片单独做连续视觉审片与真实听审，再复核事实、首尾、Logo和来源。抽帧／ASR／响度／解码通过不能替代创作或听感验收；记录实际能力和覆盖范围。

每次 First Full Cut、完整候选片或返修版渲染结束，读取并执行[视频审片页面与偏好沉淀](references/video-feedback.md)：未到 `owner-review-ready` 只能用 `--audience internal` 启动带醒目标识的内部诊断页；只有内部机器门禁和 G3 全部通过且哈希一致，才可用 `--audience owner` 打开用户验收页并交付链接与视频文件。页面支持任意单帧/时间片段评论及整轮消息预览、提交状态。服务绑定真实制作对话，默认经官方 codex queue 提交；队列回执只标为 queued，目标 Agent 实际收到后再确认 agent_received。原生 MCP App 为需实测的备选。接口不可用时保留评论并如实说明，不能把保存、入队或独立 CLI 执行称为 Agent 已收到。Agent收到后按不可变快照和视频哈希定位、派单、复核并关联新版本。评论保存观察、修改建议、可抽象偏好及适用范围；本期反馈默认不升格为长期偏好。页面打开、评论保存和问题关闭均不代表连续视听验收或用户批准成片。

交付成片、可编辑工程、字幕、透明Logo、必要分轨、来源台账、审核记录及真实未完成项。不要把预览说成导出，把渲染成功说成创作验收。若出现阻碍，完成不依赖它的工作，说明最小缺失条件。

## 持续沉淀

用户要求复盘或更新流程时，将明确反馈改成“适用场景→规则→检查证据”；通用规则进此skill，具体镜头/选题事实留项目。用户明确更改偏好时覆盖旧规则，避免矛盾累积；不把一次技术故障上升为普遍限制。

审片页面反馈按[偏好沉淀合同](references/video-feedback.md)处理：用户显式标为长期候选后，由对应专业岗提炼、独立审核岗核对适用范围和冲突；候选不等于已确认规则。执行优先级为本期明确选择、已确认长期偏好、skill默认值。仅收藏案例或批准一次镜头不构成永久偏好授权。
