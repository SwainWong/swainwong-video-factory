# 一定不能做 MUST NOT

[返回主入口](../HARNESS.md) · [失败处理](../04-verification/index.md)

这些是已存在规则的反例边界。命中后禁止用总分、进度或成本抵消；修复受影响产物后再检查。严重度按原审核合同判定，不将所有问题一律命名为 Critical。

| ID | 一定不能做 | 常见借口／识别证据 | 正确处理与范围 |
|---|---|---|---|
| N01 | 用占位、隐藏默认或自己填 `brief_confirmed=true` 绕过确认 | “用户让自主执行，所以所有字段都算同意” | 回到 M01；已明确授权的可见默认可沿用 |
| N02 | 静默更换音色、语言、平台、时长、方向、预算或拿旧确认放行新配置 | 输入哈希不同、无确认依据 | 回到 M02，列差异、确认新版本 |
| N03 | 编事实、台词、亲历、人物心理、账号互动数或伪造执行结果 | 为已锁定观点补造证据 | 退回事实与脚本；事实冲突不能被方向锁定压过 |
| N04 | 把旧阶段素材当当前现场，或以无关实景代替关系和机制 | “角落注明年份就够了” | 按 M03、M04 换证据或明确改变叙事范围 |
| N05 | 同片重复第三方原始素材或一般整镜图表／动画效果 | 裁切、转载、换数据、换 ID、回扣、凑比例 | 依 M06 查原始身份和观感结构，换新素材或新表达；保留既有 A-roll与固定包装范围；[D01](../../references/explainer-motion/foreground-depth-title.md)仅在不同章节、不同原始素材的章节标题包装中可复用，不豁免同源重复或一般图表模板 |
| N06 | 用字幕、固定标题、推拉、装饰循环为纯素材超过 5 秒开例外 | “画面一直在动” | 只有原规范定义的实质 DataMagic 讲解延时例外；记录语义步骤和结束点 |
| N07 | 用 fps、状态数量、位移或静帧证明动作自然，用拆肢旋转省略表演因果 | “已导出 30fps，所以连续” | M12 正常速度查接触、形变、发力、结果；不能用代码几何冒充纸艺主体 |
| N08 | 用现成模板反推内容，或同一套整镜换皮冒充新设计 | 选型只有名词命中、无观众问题和视觉任务 | 回到 M04、M06；共享 CI 与基础代码本身不违规 |
| N09 | 把 README、克隆仓库、统一 prompt 或源代码审查说成运行时接入 | 无实际渲染／目标平台证据 | 按 M05 分别报告研究、渲染、导入、视听状态 |
| N10 | 把 mood 字段当引擎已执行情绪；机械切词、轮流变速、加静音冒充自然表演 | 参数不支持或无真实试听 | 按 M08 查能力与音频，保持已选声音，缺能力如实报告 |
| N11 | 默认全静音实拍、叠两个人声抢话，无故移除已要求贯穿的BGM；动画岗只交无声画面推给后期补SFX，或把BGM烧入各动画片段造成重复叠加/重启；同一动画逐帧/逐状态重触发、短音堆成长音（打包单文件也不豁免） | 时间轴/实际音轨、事件组映射、源片段或生成路径、真实听审 | 回到 M09；明确设计的声音留白按本期合同处理 |
| N12 | 主 Agent 或作者冒充独立审核，暗示预期 PASS，或沿用失效版本 PASS | 审核身份、输入版本、实际覆盖不成立 | M13、M15 重新送审；工具缺失保持未完成 |
| N13 | 用解码、ASR、响度、抽帧、播放进度或评论关闭代替连续视觉审片与真实听审 | “检查都绿了，所以成片全部通过” | 分项报告实际完成范围，不升级证据等级 |
| N14 | 把保存说成锁定／派单，把 queued 说成 agent_received，把预览或 `NON_RELEASE_TEST_RENDER_OVERRIDE` 说成视频完成／最终交付 | 缺对应状态的真实回执、候选视听门禁或最终文件 | M01、M14–M17 按实际状态报告；测试 override 只能是显著标注的诊断候选 |
| N15 | 擅自删除人类原始素材、上传声音样本到未授权服务、公开发布，或冒称素材已获独立许可 | 制作授权被扩展为其他授权 | 保留原件、依据本期范围处理；用户确认授权如实登记；一次性本地制作例外不等于公开发布许可 |
| N16 | 把本期反馈、一个案例或一次技术故障直接升格为永久偏好／普遍限制 | 无长期确认或适用范围 | M18 区分本期、候选和已确认规则 |
| N17 | 用户禁止矢量时仍用 SVG、代码几何或通用矢量插画，并用布局唯一、信息图需要或运动不同辩解 | 最终画面与简报 `visual.forbidden_asset_types` 冲突 | 回到⑤/⑥替换为允许的实拍、光栅裁片或其他明确获准资产；重新看样段 |
| N18 | 同时启用全局烧录字幕、同名 VTT/SRT 自动字幕、编辑器字幕轨或未清理源片字幕，造成两份观众字幕 | 工程字幕渲染器清单与最终画面 | 只保留简报锁定的唯一字幕权威；源字幕换干净源或安全处理，最终像素复核 |
| N19 | 为尽快出 First Full Cut 而使用占位稿、缺章稿或未核事实；或反过来先把前 30–45 秒做到成片级才开始整片 | “粗剪可以先瞎写”“先把开头磨到能交付再说” | 脚本先达到可生产标准；随后优先形成完整时间线，局部技术小样只能并行、不阻塞整片 |
| N20 | 把“一小时内”或其他固定时长当作 First Full Cut 的质量放行条件，或因未耗满时间继续等待 | 用钟表替代最低完整播放条件 | 只记录 `time_to_first_full_cut` 作为效率指标；条件成立即交，未成立则报告具体阻塞 |
| N21 | G3 或内部门禁未完成时启动 owner 审片页，或把内部诊断链接提交给用户验收 | “页面能打开就先让用户看”“技术报告都绿了” | 只能 `--audience internal` 并显著标注诊断；`owner-review-ready` 与候选哈希完全一致后才可 `--audience owner` |
| N22 | 用固定间隔抽帧代替逐镜起点／中点／终点覆盖，导致短闪卡、短字幕或瞬时错位漏检 | “每两秒一帧已经覆盖全片” | 每个实际镜头至少核起点、中点、终点；可读页检查最短停留，动态质量仍需正常速度连续观看 |
| N23 | 在门禁中硬编码 `true`、`0`、`PASS` 或照抄 manifest 自报值，或让产物作者用同一报告给自己的语义判断签独立 PASS | 失败输入仍显示 `actual=true`；测试只有正常路径；“我把 semantic_status 写成 contextual，所以不存在错配” | 门禁退回开发：从实际文件重算，补负向 fixture；作者只能交生产自检，语义、事实和观感由独立角色审核 |
| N24 | 把“第三方覆盖至少 X%”理解成越接近100%越好，用68个5秒素材和同一 motion 模板铺满整片 | 比例绿了，但机制、转折和结尾全部变成素材轮播 | 把比例当下限；按意群保留获准的原创光栅／纸艺／实拍合成解释段，纯素材仍遵守3–5秒，运动结构按视觉任务实质区分 |
| N25 | 为贴死目标秒数而整体加速旁白、压缩停顿，或把97%以上口播占用率当成“内容充实” | 总时长合规但听感连续赶读、动画和证据没有呼吸窗口 | 简报范围内优先延长整片、恢复自然句段和章间停顿；保持音色，重新听审语速、重音与连接 |
| N26 | 用户已经指定独立制作对话后，主 Owner 对话仍直接改脚本、字幕、OpenFilm 或渲染产物 | “主 Agent 更快”“反正都在同一工作区” | 主对话只修 harness、派单、核证据和放行；生产写入交回绑定的持久制作 thread |
| N27 | 把研究／推理过程、自问自答、层级编号和反复叠甲直接当口播成稿 | “这样显得有思考”“多问几遍更有悬念” | 删除脚手架，留下最终判断和最短充分依据；机器预检后仍须独立编导通读 |
| N28 | 把一个完整句子或多个分句合并成长时间双语字幕块，或用句子数固定 cue 数量 | “完整句更准确”“自动切分已关闭” | 按最终发音切为短语级中英配对 cue；唯一渲染权威、机器门禁和最终像素可读性同时复核 |

规则原文：[制作简报](../../references/production-brief.md)、[去重合同](../../references/visual-uniqueness.md)、[审核合同](../../references/review-gates.md)、[反馈合同](../../references/video-feedback.md)、[完整主规范](../../SKILL.md)。
