# 推荐做 SHOULD

[返回主入口](../HARNESS.md)

这些是选择偏好，不因未采用而单独阻断交付。采用推荐后，仍需满足相关 MUST 与 MUST NOT。只在偏离会影响用户预期或项目目标时记录理由，不增加无必要审批。

| ID | 适用场景 | 推荐做法 | 可以不采用的情况／依据 |
|---|---|---|---|
| S01 | 第三方取材 | 优先原始实拍、官方原片、纪录片与采访 | 更合适且来源清楚的其他材料；[主规范](../../SKILL.md) |
| S02 | 第三方内部媒介比例 | 图片:实拍视频按主画面时长尽量 3:7 | 史料可得性或本期明确视觉方案不同；统计仍按 M07 执行；[CI](../../references/ci-and-media-standard.md) |
| S03 | 新选音或扩充声音 | 本地 VoiceStudio 库存优先，已核实免费 ChatCut 音色补充；首屏目标 10 个独立可试听音色 | 已有明确选音直接沿用，库存不足如实列出；[音色选择](../../references/voice-selection.md) |
| S04 | 口播配置 | 叠甲与口癖默认轻量，速度变化服务完整意群 | 本期明确表演风格不同；不能机械逐句变速；[口语配置](../../references/speech-style.md) |
| S05 | 口播真实章节开头 | 优先评估 [D01 主体遮挡标题](../../references/explainer-motion/foreground-depth-title.md)，相对编辑权重 3.0／普通候选 1.0；字体字号可配，完整原文自然排版，10 种入场按语气选 | 语义不合、主体难分割、文字不可读或本期风格不适用时改用其他表达；不是自动评分器或必用配额 |
| S06 | 真实原文／代码引用 | 优先评估已有 motion-graphics 动作方法，使用卡片、逐行显现与关键句高亮 | 其他可读表达更符合当前 CI；真实原文核验仍必须；[CI](../../references/ci-and-media-standard.md) |
| S07 | 纸艺人物与过程 | 优先完整姿态、独立透明裁片、手物组合连续状态 | 合理图集可以使用，但须按真实轮廓验切片；[主规范](../../SKILL.md) |
| S08 | 第三方画面满屏适配 | 优先等比放大围绕焦点裁切；需全貌用同素材模糊背景 | 本期明确试验其他适配方式，仍检查变形与可读性；[CI](../../references/ci-and-media-standard.md) |
| S09 | 音色被否决后的诊断 | 先分辨声音身份与节奏问题；节奏问题用同音色、同参数短句 A/B 定位 | 已明确要求换声音，或缺口不是节奏；短句通过不替代较长试音；[主规范](../../SKILL.md) |
| S10 | 局部版式或动作反馈 | 先用范围明确的小样验证 | 已有充分确认与证据不重复设关；小样不代表全片通过；[审核合同](../../references/review-gates.md) |

选型原则：先判断口播需要观众理解什么，再比较表达方案。推荐库、配方或案例不是每条视频必须使用的清单。
