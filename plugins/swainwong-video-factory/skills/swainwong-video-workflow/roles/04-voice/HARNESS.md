# 04 · 口播音频 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“口播轨与时码”负责。关键词：口播、VoiceStudio、真人原声、音色、试音、表演、快慢停、句子时码、发音、voice profile。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| A-M01 | 核验声音档案、语言和输入路径，沿用已锁定声音身份。 |
| A-M02 | 生成前明示匀速清晰或自然起伏，并记录完整意群的快、慢、停和重音。 |
| A-M03 | 按合同完成代表性试音，真实听取发音、音色、节奏和情绪表现。 |
| A-M04 | 记录实际发送给引擎的参数、输出文件哈希及句子/时间映射。 |
| A-M05 | 区分声音身份问题和节奏问题；变更后通知受影响分镜、字幕和A-roll同步。 |
| A-M06 | 在 First Full Cut 后的正式配音试验与完整候选混音中真实听取语速、停顿、重音和句间连接；听感仓促即 `REVISE`，不能用目标字速或总时长放行。 |
| A-M07 | 当简报时长范围仍有空间且旁白占用过高时，优先保留自然句段、增加意群／章间停顿并延长整片；重新生成或轻调单句须保留音色身份和参数证据。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| A-F01 | 不得擅自换音色、语言，或上传本人样本到未授权服务。 |
| A-F02 | 不得把 mood 文本、字段名、ASR 或波形当成真实表演已执行。 |
| A-F03 | 不得逐词切碎、机械轮流变速或加静音冒充自然表达。 |
| A-F04 | 不得制作或签收⑥SFX、⑫BGM、⑦最终混音的职责。 |
| A-F05 | 不得为贴死一个目标秒数而整体加速口播、压缩已设计停顿或把97%以上占用率当合格；范围内延长比赶读优先。 |

## 放行证据

声音档案核验、实际音频、参数日志、句子时码、真实试听范围和未通过项。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
