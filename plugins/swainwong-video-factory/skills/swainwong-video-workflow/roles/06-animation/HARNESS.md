# 06 · 动画与动效音效 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“可编辑动画与SFX”负责。关键词：动画、DataMagic、纸艺、图表、D01、motion graphics、animation_events、action_groups、sfx_cues、动效音效。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| G-M01 | 按逐镜语义完成画面、运动和对应SFX，并交付可编辑源与实际预览。 |
| G-M02 | 先登记 animation_events，再按故事/对象/动作意图形成 action_groups 和 sfx_cues。 |
| G-M03 | 每个动作组选择 one_shot、continuous_gesture、existing_sound 或 exempt，并记录依据。 |
| G-M04 | 验证真实数据、层级、裁切、碰撞、阅读时间、动作接触和最终目标平台运行状态。 |
| G-M05 | 适配全片CI，登记库/commit/配方/运行时/许可/props/补丁/渲染及导入状态。 |
| G-M06 | 动作节奏变化后重对齐SFX，并通知⑦；影响全片音乐结构时同时通知⑫。 |
| G-M07 | 逐镜核对简报的素材允许／禁止类型；命中禁用 SVG、代码矢量或通用矢量插画时立即返修，不能用布局签名唯一或信息图语义豁免。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| G-F01 | 不得只交无声动画、空cue表或‘后期再补音效’说明。 |
| G-F02 | 不得为每帧、逐字、逐行或组内补间反复触发声音，或用短音堆积冒充长运动声。 |
| G-F03 | 不得把⑫跨镜BGM烧入动画交付，或把⑦最终混音当成本岗完成。 |
| G-F04 | 不得以README、clone、统一prompt、组件ID、渲染成功或静帧代替接入和视听验收。 |
| G-F05 | 不得重复套用一般整镜结构/动画效果；D01仅按真实章节的有限例外执行。 |
| G-F06 | 不得用代码绘制的线、块、图标或平滑矢量主体替代被禁止的视觉素材；代码只可驱动已获准资产的时序、位置、缩放和遮挡。 |

## 放行证据

源码/工程、动画与独立SFX哈希、事件-组-cue映射、复建命令、目标平台预览及实际视听范围。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
