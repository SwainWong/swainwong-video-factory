# 11 · 事实与引用审核 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“独立事实审核报告”负责。关键词：事实审核、引用审核、claim、人物、日期、阶段、数字、因果、上下文、来源、unknown。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| F-M01 | 独立核每个关键claim及对应画面，记录来源、入出点、事件/拍摄/发布日期和上下文。 |
| F-M02 | 核人物、地点、物件、比赛/事件阶段、数字口径、计算、因果与引文完整性。 |
| F-M03 | 区分原始证据、转载和未知；事实与方向冲突时提交证据并阻断依赖错误结论的生产。 |
| F-M04 | 检查文字正确但画面错误、年代错配、Logo/奖项/场合误认等跨模态问题。 |
| F-M05 | 绑定输入版本和实际覆盖，修改后复审受影响claim/scene。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| F-F01 | 不得把转载、搜索摘要、字幕或旁白自身当作独立事实证据。 |
| F-F02 | 不得用年份小字治愈当前事件配旧现场的语境错误。 |
| F-F03 | 不得为已锁定观点删冲突证据、编来源或把unknown写成PASS。 |
| F-F04 | 不得修改研究/脚本后继续冒充同一变更的独立审核者。 |

## 放行证据

审核者身份、版本哈希、claim/scene-source表、原文范围、冲突/未知、修复和复审记录。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
