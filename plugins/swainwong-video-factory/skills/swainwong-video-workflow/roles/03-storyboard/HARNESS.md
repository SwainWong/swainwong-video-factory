# 03 · 分镜与视觉设计 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“逐镜视听合同”负责。关键词：分镜、shotlist、视觉任务、观众问题、动作因果、层级、路径、时码、声音窗口、资产状态。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| S-M01 | 每镜先写观众问题、本镜答案及对应句子/claim，再选择画面。 |
| S-M02 | 写清人物阶段、场景、对象关系、动作因果、入出点、路径、层级、接触与声音主次。 |
| S-M03 | 涉及形变和身体动作时定义关键状态、帧区间、施力、接触和结果。 |
| S-M04 | 预先分配唯一原始素材和实质不同的动画结构，并登记疑似重复。 |
| S-M05 | 标注资产状态、来源/权利、制作负责人、依赖和不可执行风险。 |
| S-M06 | 每个实际画面单元绑定 sentence_id、claim_id 或明确 illustrative_only、fact_source、event/date scope 和 semantic_status；机械验证不得存在 direct_mismatch。 |
| S-M07 | 本岗自检的每个 actual/PASS 必须从实际 units、文件、哈希或 ID 集合计算，并有负向 fixture；自检只能证明合同完整，不能替独立 G1 签语义 PASS。 |
| S-M08 | direct_evidence 必须登记观众可见的 evidence origin；主画面和事实截图两套 origin 一起查重，同一网页换裁切仍为同源，只能形成一次连续证据窗口。 |
| S-M09 | 把锁定第三方比例当下限而非最大化目标；按意群安排获准的原创解释段，unit时长和motion_sequence由观众问题、动作与证据阅读任务决定。 |
| S-M10 | 每个 direct_evidence 单元必须把可见主张映射到唯一事实源、精确段落／截图裁区、日期限定和绝对屏显区间；contextual、illustrative、original explanation 不得携带可见证据声明。 |
| S-M11 | G1 送审前逐项核对 direct_evidence capture receipt：最终 URL 已实际打开、支持原文可见、locator 与截图/文件哈希可复核、捕获时间和响应状态齐全；任一失效或空壳即 REVISE。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| S-F01 | 不得按名词检索结果或现成模板倒推叙事表达。 |
| S-F02 | 不得用推拉、换字幕、镜像、调色或换 ID 伪装新画面。 |
| S-F03 | 不得把未定义镜头交给生产岗边渲染边补设计。 |
| S-F04 | 不得以静帧、fps 或状态数量代替正常速度动作设计和验收。 |
| S-F05 | 不得按文件名、素材顺序、取模或固定‘每三格插图’等规则轮转资产填满时间线；比例目标不能覆盖逐句语义匹配。 |
| S-F06 | 不得在验证脚本中硬编码 true、0 或 PASS，照抄本岗自报 semantic_status 证明无错配，或把本岗自检冒充独立视觉／事实审核。 |
| S-F07 | 不得只对 primary_source 查唯一性而忽略事实截图／摘录叠加层，也不得用不同 claim、crop、unit ID 将同一来源页面伪装成独立画面。 |
| S-F08 | 不得用几乎全片第三方素材、固定5秒切镜和相同motion模板机械满足比例；比例 PASS 不能覆盖视觉任务与节奏失败。 |
| S-F09 | 不得用搜索摘要、缓存片段、旧截图存在或 HTTP 200 但正文空壳替代当前可打开的事实证据。 |

## 放行证据

shotlist/视听合同版本、逐镜字段完整度、唯一性预检、direct-evidence capture receipts、动作状态与依赖清单。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
