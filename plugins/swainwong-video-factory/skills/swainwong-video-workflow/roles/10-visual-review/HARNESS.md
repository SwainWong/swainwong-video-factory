# 10 · 视觉语义与美术审核 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“独立视觉语义报告”负责。关键词：视觉语义、美术审核、观众理解、误读、对象、关系、遮挡、排版、品牌、图表、去重。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| V-M01 | 先看实际画面/连续片段，再读实现说明；逐镜写观众首先看到和理解什么。 |
| V-M02 | 核对对象身份、关系归属、动作因果、地域/阶段、标签、图表和口播是否一致。 |
| V-M03 | 检查第三方素材和一般整镜效果第二次使用、同源派生及短镜遗漏。 |
| V-M04 | 检查字幕、来源、Logo、进度条、安全区、满屏、裁片边缘、碰撞和运动极值。 |
| V-M05 | 动态动作按正常速度看；局部截图只给局部结论并标未覆盖。 |
| V-M06 | 对照简报检查禁用素材类型，并清点所有观众字幕渲染来源；矢量禁令或双字幕命中即 `REVISE`。 |
| V-M07 | 对最终进度条检查全部章节同时可见、段宽按真实时长、标题／分隔线存在、各边界前后与全片线性累计填充；图层存在或单条全局线不通过。 |
| V-M08 | 清点低清放大镜头：核源宽高、输出框、zoom、有效线性放大倍率与最终像素；可解码和满屏不等于清晰。 |
| V-M09 | 每个实际镜头至少检查起点／中点／终点，逐一捕捉短闪卡、瞬时双字幕、Logo／来源跳位；可读页不足最短停留即 `REVISE`。 |
| V-M10 | G3 输出一份 `swainwong.review.v1`，绑定 candidate SHA、独立 reviewer／producer 身份、覆盖与能力，并逐项填写 `visual_asset_policy`、`subtitle_single_authority`、`chapter_labels_and_segmentation_visual`、`brand_overlay_visual`、`source_perceived_quality`、`short_shot_readability`；不能用制作自检或机器台账代替。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| V-F01 | 不得依据代码、分镜意图或文件名猜观众应该看懂。 |
| V-F02 | 不得用固定间隔抽帧证明短镜无重复、动作自然或全片无遮挡。 |
| V-F03 | 不得把裁切、换色、换字幕、换数据、换ID的同构画面判成新表达。 |
| V-F04 | 不得越权修改画面后继续以独立审核身份签同一变更。 |

## 放行证据

审核者身份、输入哈希、逐镜/时码观察、并排重复证据、动态覆盖、问题与复审状态。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
