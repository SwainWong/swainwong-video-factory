# 07 · 剪辑与声音合成 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“可编辑时间线与候选导出”负责。关键词：剪辑、时间线、OpenFilm、ChatCut、合成、字幕、SFX、BGM、混音、候选导出、timeline。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| E-M01 | 只在锁定平台工程中组装，并绑定所有上游产物的版本/哈希。 |
| E-M02 | 保留口播、原声、SFX、BGM可编辑独立轨，按声音主次和让位窗口完成混音。 |
| E-M03 | 落实字幕、来源、Logo、进度条、安全区、满屏适配及A-roll同步。 |
| E-M04 | 从实际时间线导出素材区间和动画实例，执行唯一性及3–5秒规则检查。 |
| E-M05 | 可生产脚本和粗分镜就绪后，立即建立目标时长完整时间线；每句用正式或显式临时画面覆盖，导出 First Full Cut 并记录复建方式。 |
| E-M06 | First Full Cut 后在同一整片上横向替换素材、配音、动画/SFX、BGM与混音；上游实质变化时只标记受影响时间线失效。 |
| E-M07 | 锁定一个观众字幕渲染权威，清点全局烧录层、VTT/SRT自动轨、编辑器字幕轨及源片烧录字幕；工程预览与最终像素均不得出现两份。 |
| E-M08 | First Full Cut 生成哈希绑定完整性报告；最终候选提交 `swainwong.final-visual-gate.v2`，检查分段导航最终像素、同源连续区间、有效放大倍率、禁用主画面、可读页时长和 Logo；剪辑岗不得自行生成 candidate AV PASS。 |
| E-M09 | 对每个实际镜头覆盖起点／中点／终点；固定间隔抽帧只能补充，不能替代短镜覆盖。候选机器门禁通过后交 G3，等待独立审核。 |
| E-M10 | 逐单元继承 sentence/claim/source/event-date/semantic_status，不得在构建时重排或丢字段；最终导出须在明确 cue 内核对单一中英字幕像素，而不只检查 VTT 和配置存在。 |
| E-M11 | source-use manifest 必须同时登记主画面与事实截图叠加层 origin；同一网页不同截图仍按同源处理，最终 visual units 把 evidence_overlay_origin_ids 传入机器门禁。 |
| E-M12 | 最终 visual units 从实际时间线计算第三方覆盖率及其内部视频占比，并把简报锁定下限交 coverage_policy；比例合格仍需保留分镜定义的原创解释段。 |
| E-M13 | 将分镜 visible_evidence 的 claim/source/locator/date/绝对屏显区间原样落实到最终像素和 manifest；不得用一个泛化网页截图声称证明多个未显示段落。 |
| E-M14 | 以最终口播音频为时钟，把中英字幕切成一一对应的短语 cue；每个 cue 运行 `subtitle_phrase_gate.py` 检查时码、时长、字数、阅读速度和单语行数，再做最终像素可读性审核。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| E-F01 | 不得静默改文案事实、声音身份、素材权利、动画语义或锁定CI。 |
| E-F02 | 不得默认全部实拍静音、叠两个人声抢话或抽掉已要求贯穿的BGM。 |
| E-F03 | 不得把背景遮满后虚算第三方主画面，或以切镜/推拉/字幕变化掩盖重复。 |
| E-F04 | 不得把时间线预览说成最终导出，或把导出成功说成创作验收。 |
| E-F05 | 不得替⑥修动作SFX设计、替⑫选全片音乐后隐藏责任变更。 |
| E-F06 | 不得因轨道或文件存在就宣称SFX/BGM已配置，也不得以全片响度掩盖单轨在上下文中不可闻。 |
| E-F07 | 不得在完整粗剪出现前把任一 30–45 秒片段精修到成片级，也不得用缺章或占位文案抢跑。 |
| E-F08 | 不得用项目自建 JS 的 PASS、图层存在、DOM 公式或素材可解码代替插件最终视觉门禁；不得把制作岗自检写成独立 G3 或 candidate AV PASS。 |
| E-F09 | 不得按素材数组顺序、取模或固定间隔机械分配画面，也不得仅因比例、哈希、解码和来源出现门禁通过就忽略画面与口播语义错配。 |
| E-F10 | 不得只核 primary source 唯一性、却让重复事实截图以 overlay 名义跨镜复用；不能用不同 crop 或 claim ID 绕过。 |
| E-F11 | 不得把整句或多分句合并成一个长时字幕块，也不得用固定 47 句、禁用自动切分或‘完整句更准确’覆盖短语级可读性合同。 |

## 放行证据

工程/时间线、候选文件与哈希、轨道和素材区间清单、混音参数、复建命令及自检范围。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
