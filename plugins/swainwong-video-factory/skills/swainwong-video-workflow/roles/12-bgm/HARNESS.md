# 12 · BGM配乐 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“独立BGM轨与音乐使用表”负责。关键词：BGM、配乐、跨镜头、段落情绪、循环、交叉淡化、ducking、人声让位、音乐授权、music cue。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| B-M01 | 根据全片主线和段落情绪设计跨镜接续，不随每个动画片段重启音乐。 |
| B-M02 | 登记音乐来源/许可、素材哈希、全片时间码、循环/交叉淡化、增益和让位区间。 |
| B-M03 | 依据口播、人物原声、环境声和⑥SFX设计ducking与留白，保持语言清晰。 |
| B-M04 | 交付独立可编辑BGM轨及上下文试听版；与⑦核对最终时间线接缝。 |
| B-M05 | 时间线或口播结构变化后复核受影响段落并更新音乐使用表。 |
| B-M06 | 在完整候选混音中实际确认BGM按要求可闻；First Full Cut 可将BGM列为显式 placeholder，但后续不得以轨道存在代替真实可闻。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| B-F01 | 不得承担⑥动画事件SFX，或把短音乐性动作提示一概改名为BGM。 |
| B-F02 | 不得把BGM烧进动画文件、只交不可分混音或替⑦签最终混音完成。 |
| B-F03 | 不得在用户要求贯穿时无故抽掉BGM，或用整段静音代替已设计的让位。 |
| B-F04 | 不得用cue数量、波形、响度或播放成功替代完整上下文真实听审。 |
| B-F05 | 不得使用来源/许可不明音乐，或把本集音乐固化成永久默认。 |

## 放行证据

独立音乐文件/工程与哈希、music-use表、来源许可、实际试听范围、与人声/SFX让位及接缝复核。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
