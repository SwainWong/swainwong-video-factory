# 09 · 编导与视听审核 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“独立编导审核报告”负责。关键词：独立审核、编导、叙事、节奏、爆点、人物弧、原声窗口、实际听审、PASS、REVISE。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| Q-M01 | 首次判断独立完成，不先读其他审核人的结论或预期答案。 |
| Q-M02 | 检查主线、钩子/爆点、承诺回收、人物弧、动作因果、节奏和制作可执行性。 |
| Q-M03 | 对 First Full Cut 做完整结构诊断；对成片按正常速度实际观看并真实听审口播、原声、SFX、BGM及混音，二者结论不得混用。 |
| Q-M04 | 逐条给出场景/时码/原句、问题为何成立、严重度、证据和具体修复。 |
| Q-M05 | 明确实际覆盖与未覆盖；Critical/Important关闭且覆盖完整才签PASS。 |
| Q-M06 | 对候选片五项门禁逐项给感知结论，尤其确认口播不仓促、SFX可辨、BGM可闻；不能合并成“音频正常”。 |
| Q-M07 | G3 输出一份 `swainwong.review.v1`：candidate SHA、reviewer_id、producer_id、正常速度最终文件审核方法、0–结尾覆盖、真实听审能力、逐项 findings 与状态。不能只写自由文本结论。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| Q-F01 | 不得由作者或主Agent换身份自审，也不得接受暗示通过的答案。 |
| Q-F02 | 不得用脚本可行、静帧、ASR、波形、响度或解码代替实际视听。 |
| Q-F03 | 不得用平均分掩盖Critical，或把旧版本PASS继承给新版。 |
| Q-F04 | 不得直接修改制作产物后继续以独立审核者身份签同一变更。 |

## 放行证据

审核者身份、输入哈希、实际看听范围、逐条问题、复审记录和最终状态。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
