# 05 · 素材与图像制作 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“素材包与来源台账”负责。关键词：素材、B-roll、图像、裁片、来源、授权、rights_status、origin_id、去重、透明PNG、source ledger。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| I-M01 | 每项素材记录 origin_id、原始 URL/路径、来源身份、日期、权利状态和可用范围。 |
| I-M02 | 按事件/阶段和语义角色选材，优先原始实拍、官方原片、纪录片和采访。 |
| I-M03 | 识别转载、截图、重编码和裁切的同源关系，向唯一性台账交接。 |
| I-M04 | 生成图像须第一眼对应真实对象，保留透明边缘、阶段、姿态和必要状态。 |
| I-M05 | 保留原始文件；输出选段建议、焦点、源入出点及素材缺口。 |
| I-M06 | 交付可执行 source-use manifest：每次使用含 origin_id、源宽高／码率、输出框、构图模式、zoom、时间线区间和有效线性放大倍率；同一第三方 origin 只能形成一个连续区间。 |
| I-M07 | 为每次使用保留 storyboard 的 sentence/claim/fact_source/event-date/semantic_status；直证、上下文和示意素材分开，发现年代、范围或对象错配立即退回。 |
| I-M08 | 对事实网页／文件生成截图或摘录时保留共同 evidence origin；同源不同 crop、截图、标注或高亮仍合并为一个 origin，并向分镜/剪辑报告重复冲突。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| I-F01 | 不得把 reference_only 素材直接标为可编辑使用，或扩张用户确认授权范围。 |
| I-F02 | 不得绕过 DRM/付费墙，或冒称取得公开发布/商业再分发许可。 |
| I-F03 | 不得把同源不同上传、截图、裁切或转码计为独立素材。 |
| I-F04 | 不得用无关旧影像、通用奖杯、简陋几何人物或错误Logo替代指定实体。 |
| I-F05 | 不得为达到第三方覆盖率或视频占比，用与当前句子无关的通用素材机械填充，或在构建时丢掉 illustrative_only 等限定。 |
| I-F06 | 不得把同一事实页面的不同截图当成多项唯一素材，或因主画面 origin 唯一就隐去叠加证据层的重复。 |

## 放行证据

素材文件与哈希、来源/权利台账、同源关系、透明边缘检查和事件覆盖清单。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
