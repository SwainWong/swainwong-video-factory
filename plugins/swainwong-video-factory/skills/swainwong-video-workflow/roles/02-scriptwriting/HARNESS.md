# 02 · 文案与叙事 Harness

[返回岗位方法](METHOD.md) · [工作流总 Harness](../../harness/HARNESS.md) · [岗位索引](../INDEX.md)

## 职责边界

本岗位对“标准稿”负责。关键词：文案、叙事、口播稿、句子ID、核心矛盾、钩子、转折、高潮、承诺回收、引用映射。这些词用于 Codex 路由和任务包检索，不扩大岗位权限。

## MUST DO

| ID | 必须做 |
|---|---|
| W-M01 | 围绕一个核心矛盾组织钩子、完整事件、转折、高潮和落点。 |
| W-M02 | 为口播意群建立稳定句子 ID，并把事实句映射到 claim 和来源。 |
| W-M03 | 登记提出的问题、对象和承诺如何回收；关键缺口显式回传。 |
| W-M04 | 按锁定语言、目标时长、叠甲/口癖强度与节奏方案写可朗读标准稿。 |
| W-M05 | First Full Cut 前关闭正文中的 TODO、缺章和未经核验的关键事实，并取得编导与事实审核；不得用占位稿换速度。 |
| W-M06 | 实质改稿时列出对分镜、音频、字幕、图表和时间线的影响。 |
| W-M07 | 提交定稿式口播：一句只承担一个有效信息，直接给结论、证据或转折；运行 `script_style_gate.py`，再由独立编导检查是否仍像思考过程或自言自语。 |

## FORBIDDEN DO

| ID | 禁止做 |
|---|---|
| W-F01 | 不得自行补造研究包没有支持的事实、引用、台词或人物情绪。 |
| W-F02 | 不得以总结句掩盖未交代的过程、对象或结果。 |
| W-F03 | 不得静默改变观点、语言、时长范围、声音身份或其他锁定条件。 |
| W-F04 | 不得兼任独立审核，或把脚本可行写成成片已通过。 |
| W-F05 | 不得把研究、推理和自我修正过程写进口播成稿；禁止连续使用‘先说清楚／真正的问题／如果答案只是／显然没这么简单／先排除／更值得追问／第一层第二层／更准确的说法’等脚手架推动叙事。 |
| W-F06 | 不得靠重复反问、防御性限定、层级编号或同义改写叠加时长；事实限定只在改变含义时保留一次。 |

## 放行证据

标准稿版本/哈希、句子-claim 映射、承诺回收表、字数/估时与变更影响清单。

没有上述实际证据时不得将本岗位写成 `READY`。文件存在、字段完整或工具成功只证明相应技术事实；需要看、听或独立判断的项目仍按实际覆盖报告。

## 失败处理

命中 FORBIDDEN、输入版本不一致、关键证据缺失或产物无法复建时，标记 `REVISE`；只完成局部范围时标记 `PARTIAL`；能力或资源不可用时标记 `UNAVAILABLE`。列出问题位置、证据、责任边界、最小修复和受影响下游。不得越权代替其他岗位修复后继承其审核身份。
