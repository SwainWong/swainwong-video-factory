# 初始制作简报与锁定合同

每次新制作或成片重编，先收齐并锁定人类的初始条件，再派资料研究、文稿、分镜、动画匹配和执行任务。入口是同一份可读、可追溯的制作简报；表单、对话和已给资料均可提供输入，不要求用户重新填写已明确的答案。

## 必须确定的条件

| 条件 | 锁定内容与检查 |
|---|---|
| 主题与核心表达方向 | `topic`、`viewpoint`非空。方向可以是中立的核心问题、比较视角或待验证的假设，不强迫先给定结论；仅写“以后再想”不算确定。 |
| 目标观众与观看目的 | `audience`、`purpose`明确，作为研究深度、术语和信息密度依据。 |
| 画幅与交付 | 16:9、9:16等实际选择；制作平台、分辨率和交付范围已确定。 |
| 时长 | 目标锚点加提前/延后容差，或明确最短/最长区间；包含片头片尾。目标5分钟、前后各1分钟=4–6分钟，不能把“宽2分钟”自行解释为±2分钟。 |
| 口播语言 | `voice.spoken_language=zh-CN / yue / en / custom`；custom须在`voice.language_notes`附具体语言/方言说明。与字幕语言分别记录，不从字幕反推口播语言。 |
| 主声音来源与音色 | VoiceStudio真实档案、真人录制原声，或第三方平台的真实声音档案；记录选择与核验状态，见下节。 |
| 字幕语言与渲染权威 | 明确中文、英文或中英双语；若用户明确要求无字幕，登记为显式选择。另锁定 `subtitles.render_authority`，说明由 OpenFilm 全局层、编辑器字幕轨或其他唯一机制负责观众字幕；不能同时启用同名 VTT 自动字幕与烧录层。 |
| 品牌、视觉与素材类型 | 默认/自传/无Logo的选择，品牌与视觉风格，A-roll来源、音频模式、布局和覆盖意图；同时锁定 `visual.asset_policy` 与 `visual.forbidden_asset_types`。用户禁止矢量素材时必须写入简报，不能用“信息图”“唯一布局”或代码驱动作为豁免。无A-roll也要是明确的有效选择。 |
| 制作边界 | 预算、磁盘/素材清理策略、协作参与方式、使用与交付范围；引用边界或必用素材有要求时一并记录。缺省值须可见并获人类接受。 |

不要求初始阶段已经完成研究、逐镜设计、录制或动画选择。主线具体组织、爆点、每个take和图表配方是后续专业岗的产物；不得以缺少这些后续产物为由无限追问人类。

## 默认值与人类确认

用户当前及此前已明确的输入直接沿用；有冲突时以最新明确选择为准。对其余条件展示有效默认值和完整预览，人类一次确认整份简报即可，不逐项重复批准。skill中未展示的值不能冒充已确定；只有用户明确授权采用相关默认并已能查看其内容时，才记为接受默认。

入口接收 `brief_confirmed=true`，并保存确认依据、时间、简报版本/哈希和每个字段来源（用户显式输入、用户接受的可见默认、已有明确输入）。布尔值不是Agent自己代填的人类意愿；保存请求必须对应人类实际提交或可追溯的明确指令。`brief_lock`记录`config_sha256`、`revision`、`confirmation_basis`和`scope`；`entry_gate`绑定相同配置哈希，不能用旧配置的确认或校验结果放行新配置。“不需后续审批”不会使缺失的主题、方向或声音选择自动变成已知，但已有明确默认授权应沿用。

## 声音路线核验

- **VoiceStudio：** 用户选择当前库存中的稳定档案ID及实际显示名称。核验档案存在与实际可用状态，记录已知语言能力；别名/模板不当作已就绪独立声音，引擎`available`不为`true`时记录`pending_verification`和缺口，不能据档案存在就放行。实际语言发音和表演试音属于后续音频准入，尚未试音不单独阻止已锁定条件的内容研究，亦不允许擅自更换语言或音色。
- **真人录制：** 初始必填`a_roll.speaker_ref`明确录制人及“使用该人的原声”，即是音色选择，不要求VoiceStudio档案；表单可提供可改的“本人”作为可见默认，接受后记录选择。原片尚未录制时可登记 `awaiting_recording`；初始条件可锁定，但需原片的制作步骤等待实际接收与take验收。
- **平台数字人声音：** 初始指定平台、必填`a_roll.performer_ref`人物档案和真实声音档案引用；通过可用连接器读取/核实。仅输入名称、ID或描述时保留 `pending_verification`，不能写已通过；不得擅换默认声音来消除缺口。
- **已批准音频驱动数字人：** 明确外置音频来源及已选声音；平台不支持该输入时报告能力缺口，不能改用平台声音代替。文稿与音频尚待生产不等于声音身份未定。所有`source=avatar`入口（含VoiceStudio音频驱动）先标记`pending_verification`，初始必填人物档案也不等于已核验；只有平台人物及所需声音/输入路径核验完成，才能进入锁定关口。

主声音语言与字幕语言分别验证。双语字幕的翻译需依最终实际说出的内容生成，不能先按估计音频冻结字幕时码。

## 状态、校验与派单

主Agent只收集人类输入、调用入口校验、转交状态与问题、协调专业岗；不自己充当事实/创作审核。字段完整性、枚举、范围、条件必填与版本一致性由可用表单/校验工具检查，音色/人物身份由可用库存接口核验；工具不存在时报告未接通，不编造机器检查或已派单。

1. `draft`：至少一项初始条件缺失、存在歧义或尚未人类确认。只做输入整理、可选项/库存展示、入口能力核验；不派后续研究、匹配动画或生产。
2. `brief_lock.status=user_confirmed`：人类确认了明确版本，字段校验、必要声音/人物身份核验仍可能待完成。保存不等于初始关口通过；必要平台档案待核验时登记`entry_gate.status=pending_verification`。
3. `entry_gate.status=locked_for_dispatch`：必填条件齐全、范围合法、相互兼容、必要档案已核验，人类确认仍对应当前版本。校验记录包含实际工具、检查时间、版本/哈希、阻塞项；主Agent只能把这一版本传给后续岗位。
4. `dispatched`：有实际派单回执、目标岗位及其输入版本。自动派单连接尚未接通时保留已锁定/待派单状态，不把保存成功写作执行开始。

缺项集中列出，尽量用一次表单/汇总补齐；不得通过空字符串、随意占位、不可见默认或主Agent假装人类确认绕过。单独“讨论流程、复盘旧片、修改规范”不属于启动一条新制作链，不需要为这类工作收齐制作表单。

## 派单与产物依赖

研究任务收到简报ID/版本/哈希、主题、核心问题/方向、受众、观看目的、事实边界和目标时长；不得只转发一个主题词。文稿、分镜、音频、素材、动画及剪辑随后接收同一简报版本与各自上游产物，任何已失效输入都不能作为执行依据。所有交接同时标记尚待产出的素材或文稿，不把方向锁定误称为全片脚本锁定。

## 条件变更与事实冲突

主Agent或子Agent不得静默改动已锁定的语言、音色、画幅、时长范围、方向、Logo、平台、预算或其他初始选择。需要变更时提出字段差异、理由及影响，由人类确认新版本；旧版本和历史报告保留。校验工具/依赖清单据变更标记受影响下游产物为失效，相关岗位重做或复核；未受影响产物可保留但须登记复用依据，不继承不适用的PASS。

锁定方向不是锁定事实结论。研究发现事实与预设观点冲突时，研究/事实审核岗提交证据与可行方向，主Agent回传人类修改或重述方向并确认新版本。不得为守住原观点删证据、编事实或继续以错误立场生产；仍可在原授权范围整理冲突证据，但依赖受争议结论的文稿和制作暂停。

本合同是执行要求，不宣称当前表单、平台连接器、校验工具、锁定状态机或自动派单已全部实现。交付必须分别说明已保存、已核验、已锁定和已派单的真实状态。
