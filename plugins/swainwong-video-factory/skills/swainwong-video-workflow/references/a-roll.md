# A-roll：真人与数字人口播

适用于主持人讲述主线的画面。A-roll 是叙事角色，不以素材由人拍摄还是由第三方平台生成划分；历史采访、新闻片段等被引用内容仍是第三方证据素材，不能改名 A-roll 绕过规则。

## 入口与职责

沿用一个主 Agent、12 个子 Agent 职责（①–⑪加独立⑫BGM），按任务范围调度。主 Agent 接收用户选择、分派依赖、汇总报告和返修；不代替制作岗或审核岗执行、签发 PASS。A-roll 是既有流程的一条分支，无须自动增加岗位。

| 岗位 | A-roll 责任与交接产物 |
|---|---|
| ②文案 | 交付带稳定句子 ID 的口播稿、字幕稿、术语表；录制后口头改写需回写版本 |
| ③分镜 | 给出逐句出镜/退场、全屏/分屏/PiP、B-roll 关系、主体安全区与布局切换点 |
| ④口播音频 | 真人原声选 take、清理与实测对齐；或交付已获授权的音频驱动文件；不擅改声音 |
| ⑤素材与图像 | 给人类录制清单、接收并登记原片，或调用用户选定且当前可用的数字人服务；保管来源与生成记录 |
| ⑥图表动画与动效音效 | 交付留好人物槽的内容层、布局参数、动效及同步SFX；按[动画音效合同](animation-sound-design.md)保留独立轨，不把配声留作无责任人的后期任务；先核实配方支持，不用静态头像假装 A-roll |
| ⑦剪辑合成 | 在选定剪辑平台装配真实 A-roll、B-roll、图表及混音，管理所有媒体时钟与动态裁切 |
| ⑧技术交付 | 探测媒体、检查时间码/依赖/导出，维护可编辑工程和安全清理清单 |
| ⑨编导与视听审核 | 连续检查表演、句意、节奏、原声处理、唇音同步与出镜目的 |
| ⑩视觉语义与美术审核 | 在设计、样段、成片检查人/内容关系、裁脸、遮挡、边缘和版式 |
| ⑪事实与引用审核 | 复核说出的事实、补录改词和来源；数字主持不能冒充事件当事人或伪造采访 |
| ⑫BGM | 独立配置跨A-roll/B-roll及全片的音乐接续、淡化与让位，交独立BGM轨；动画SFX由⑥负责 |

①资料研究按既有职责提供证据，不把数字人表演作为事实来源。

## 用户选择与有效简报

先完成[初始制作简报锁定](production-brief.md)，再派A-roll相关文稿、分镜和生产任务。默认值仅是可覆盖的候选。提交后记录最终值与来源，生产岗不得静默切换人物、音色、平台或版式。缺少原片可先完成文稿/录制清单；依赖该素材的制作标记待素材，不能报生成完成。

入口 `a_roll` 字段与取值：

| 字段 | 含义 |
|---|---|
| `source` | `none / manual / avatar` |
| `audio_mode` | 无 A-roll 时 `voicestudio`；真人录制 `recorded`；数字人选 `voicestudio / platform` |
| `layout` | `auto / full / split_left / pip_circle / pip_rounded`；auto 由③提案并接受审核 |
| `coverage` | `key_sections / throughout`，是出镜意图，逐镜安排写入 shotlist |
| `speaker_ref` | 真人路线初始必填的录制人；表单字段`aroll_speaker`可见默认“本人”可改，提交后保存为`a_roll.speaker_ref` |
| `source_ref` | 人类原片本地路径或素材描述，可先空等录制；描述不是已接收的资产 |
| `provider / performer_ref / platform_voice_ref` | 数字人平台、人物档案和平台声音引用；avatar初始必填performer_ref，使用平台声音时还须填platform_voice_ref。所有avatar入口先待核验，填值不代表人物/声音/输入能力已验证 |
| `notes` | 裁切、口吻、出镜位置、补录等附加意图 |

这只是入口表单合同，不能代替 `resolved_assets`、实测时间码或平台调用结果。真人录制不要求先选 VoiceStudio 音色。真人换声、配音或口型重生成属于显式变更：记录用户授权后走音频驱动分支，不直接覆盖原声。

## 两条获取路线与音频主时钟

**人工录制：** ②先交付可读稿及句子 ID，③提供构图/眼线/画幅建议，⑤给每段 take 的录制清单。接收原片后保留不可覆写的来源文件；④核实实际说出的内容、挑选完整意群、处理噪声和必要静音，⑧读取实际帧率、分辨率、时长及音轨。分镜初稿可先行；最终字幕与动画时点必须等待选定 take 的实测对齐。漏字、改词和术语读错回到②/④处理，涉及事实回⑪；不可用另一段声音强行贴到可见嘴型上。

**第三方数字人：** ⑤读取实际平台技能/接口，核对人物、声音及输入方式。用户可选择④提供的已批准音频驱动，或平台文字/音色生成。前者在请求中保留音频哈希和任务 ID；后者先做实际样段，下载结果后重新测量口播和字幕时间，不假设其音色等于 VoiceStudio。生成前已有授权继续沿用；新增付费或上传未经授权的人物/声音素材时不能自行扩大范围。没有可用音频输入的连接器，不把 URL 写进任意字段冒充支持；选用已支持的路径或报告能力缺口。

每个时间区间只设一条主讲人声音。原片/数字人成片自带音轨与外置音频二选一，避免双声、回声；需要替换时仍保持来源偏移与唇音同步。BGM、B-roll 环境声按主讲音轨让位。真人原声或平台实际音频一经改动，字幕、A-roll 口型、图表触发点和下游导出都需要重新对齐和复审。

## 生产交接：take manifest 与依赖

每段选用素材登记 `take_id`、`speaker_id`、`script_version`、`sentence_ids`、`origin_id`、原始路径/哈希、`source_kind`（manual/avatar）、来源/授权依据，以及实际媒体信息（fps、时长、音轨）。数字人另记平台、人物/声音档案、任务 ID、输入文稿/音频版本和输出哈希。

每个剪辑实例登记：

- `clip_id / take_id / scene_id / sentence_ids`；原片入出点 `source_in/out` 与全片 `timeline_in/out`，明确秒或帧及对应时基。
- `audio_master_ref / audio_hash / audio_offset`、选用音轨、增益和必要处理；视频源时间与音频源时间均可追溯。
- `layout / crop_focus / mask / box_keyframes / z_order`、出入场点、B-roll 引用与其入出点；记录留给字幕、Logo、来源、进度条的安全区。
- `derived_from / generated_by / keep_reason / protected_original`，用于工程重建和清理判断。

依赖链：锁定文稿与句子 ID → 录制/生成 → 选定 take 与实测音频 → 字幕与逐镜时间表 → 内容层/人物槽 → 剪辑样段 → 独立审核 → 全片导出。③可先设计版式，⑥可先做内容层；二者不得用估算音长签发最终同步通过。修改上游版本时标记依赖它的下游产物失效，不能继承旧 PASS。

## 动态画面与工具边界

支持全屏出镜、左人右内容、圆形 PiP、圆角矩形 PiP。位置、比例、圆角和切换点来自本期简报及③分镜；默认保留头顶、眼睛、嘴部和必要手势。PiP 不是静态贴图，人在说话时必须播放对应视频帧。背景 B-roll 或图表继续按自己的时间轴播放；人物出入场不能使背景重启，换布局不能重置口播。全屏转小窗在有语义目的的时点发生，不为“动态”持续漂移。

**剪辑层负责装配。** ⑦调用用户选定的 OpenFilm 或 ChatCut 工作流实现媒体导入、源片裁剪、遮罩/圆角、位置/缩放关键帧、叠加与混音；按当前可用接口验证，不以“平台理论支持”当作已接入。OpenFilm已查手册的路径是film.html视频轨、同文件#t源片裁剪、静态位置/尺寸/圆角和独立音频；film CSS不会自行播放动画。连续移动人物槽须在受支持的确定性时间页面/合成路径另做实际视频样段验证；仅按镜头切换全屏/分屏/PiP也可满足已设计的动态编排，不能把CSS动画声明当作稳定导出。页面声音不能替代film音轨。DataMagic 主要承担图表/内容层；只有读取选定配方 schema、源码、sample props 并用实际讲话视频验证后，才可由该配方承载 A-roll。

已观察到的能力陷阱（本地源码核查于 2026-10-23，后续以实际版本为准）：`presenter-chart-stage` 的 `PresenterFigure` 是 SVG 人物，schema 无视频槽；`video-data-overlay` 虽有 `videoSrc` 和 `OffthreadVideo`，源码将声音 muted 且在末尾约 1.2 秒 Freeze。它们均不能未经改编直接作为完整口播播放器。适配时需逐一检查视频时间映射、入出点、冻结行为和音轨；不支持则让剪辑层承载 A-roll，并导入图表内容层。此核查不代表已渲染或验证平台导入。

## 与现有素材规则的范围关系

授权主持 A-roll 单独分类，不套用第三方证据/B-roll 的“纯素材 3–5 秒”“同源只能一个连续选段”或“第三方:原创 8:2”默认指标。同一主持人、同一长录制的不同有效句段、稳定分屏/PiP 容器可以跨镜头使用，属于叙事连续性。**不得循环同一口型、重放 take、冻结人物或用无关讲话动作凑时长。** 内容层图表和第三方 B-roll 仍遵守既有去重规范，人物容器可复用不等于图表整镜可重复。

统计先按全片区间互斥列出 A-roll 全屏、A-roll+内容混合、仅 B-roll、纯动画；混合另记图层可见覆盖，不能重复加总。若本期仍采用 8:2，只在预先约定的非 A-roll 主画面分母统计；不自动把数字人平台输出算“第三方实拍”凑比例，也不把人物小窗挤进比例计算。主持时长由句意、表达和简报决定，持续出镜仍须有叙事必要性。

## 三道独立关口与返修

| 关口 | 输入、检查与放行 |
|---|---|
| G1 画面制作前 | 文稿/分镜、入口选择、素材状态、人物槽与时间依赖。⑨判断出镜目的和完整句意；⑩检查构图、字幕/Logo/进度条安全区和内容可读性；⑪核事实与人物来源。缺少 take 不伪报音画验证；只能放行已覆盖的设计范围。 |
| G2 First Full Cut 定整片问题 | 用真实或明确标记的临时讲话视频与实际口播时钟形成整片，覆盖布局切换、B-roll 连播、最长字幕、遮挡最不利状态。⑨定位唇音同步、切词/双声/变速风险；⑩看头脸/嘴部裁切、抠像残边、圆形/矩形蒙版、移动极值、表格/图表可读性；⑪核实际说出的内容。最终感知 PASS 只在完整候选真实看听后签发。 |
| G3 最终验收 | 三角色绑定最终导出哈希，连续看听各 A-roll 区间与转场；⑧另验完整解码、音轨、时码、素材引用和交付。数字人加查身份稳定、嘴型/牙齿/眼睛/手势异常、错误停顿、首尾冻结、平台水印和事实冒认。抽帧/ASR/数值同步检查不能代替真实听看。 |

未授权换声、口播事实严重错误或伪造人物身份为 Critical；明显唇音错位、剪断词句、双重主讲、遮嘴/裁脸、人物挡字幕/Logo/进度条/关键数据、假循环/冻结讲话、数字人明显失真为 Important 或按影响升级。存在未关闭 Critical/Important 时 REVISE，不按平均分放行。不能真实听看则 PARTIAL/UNAVAILABLE 并写覆盖缺口。主 Agent 把问题派回④/⑤/⑥/⑦等责任岗，修复后由原审核角色复审受影响段；换文稿、音轨或 take 需回溯所有依赖。

## 原片保护与磁盘清理

人类上传的原片、原声和声音档案标记 `protected_original=true`，不得因“用过了”自动删除。对用户已授权清理的第三方下载/生成中间件、代理、缓存及旧导出，⑧先列引用和替代关系：已被当前工程使用且无可重建替代的文件保留；已验收替代版本存在、当前工程不再引用的衍生物可按本期清理策略删除。若工程还引用大原片，先固化所需选段、重链接并验证可重开/可导出，再按用户授权处理可清理源文件；人类原片仍受保护。保留来源、选段时间码、哈希与删除清单。不能把磁盘策略扩大为删除用户原始录制。
