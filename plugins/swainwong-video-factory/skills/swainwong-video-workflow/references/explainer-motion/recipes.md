# 讲解动画配方与验收

这些是可重建的动作与数据规则，非平台可直接导入的模板。实现前按当前画幅和文字设计定格状态，再安排入场、阅读与退场。以下时长只是起点，按旁白及文字密度调整；10秒demo的压缩节奏不作为正式视频默认。

## C04 大数字增长

- 用途：突出单个总量或关键指标。图层：背景/媒体 → 标题与口径 → 数字 → 固定单位 → 可选强调线。
- 输入：真实终值value、起值startValue、decimals、unit、prefix、period、source；countDuration、holdDuration和主题。
- 步骤：确定真实终值及精度；按时间算进度 `p=1-(1-clamp(t/d,0,1))^3`；显示 `round(startValue+(value-startValue)*p,decimals)`；单位不跳动；定格后留足阅读时间。
- 起点：增长约0.8–1.5秒，终值约1.5–2秒，按内容调整。数字区固定宽度或使用等宽数字。
- 验收：终值/单位/精度正确，无跳位或裁切；过渡值不是观测数据，不把增长百分比当作倍数。

## C01 横条逐项对比

- 用途：同类数量的规模差异。图层：标题/口径 → 类别标签 → 共享零点横条 → 数值单位 → 比较结论。
- 输入：labels、values、periods、unit、source、scaleMax、revealTimes、growthBaseline及主题。
- 步骤：确认单位与时期可比；统一零点和线性比例 `length=value/scaleMax*plotWidth`；按讲解顺序增长横条；显示终值；两条都清楚后揭示差值或增长率。
- 起点：每条增长0.6–1秒，错峰0.3–0.8秒；结论出现后留完整阅读帧。
- 验收：比例正确、标签不碰条端。基期为0时不算百分比增长；负数改用有零轴的适当图形，不能硬套非负横条。时间窗不同需明确标注，不能自动当作同比。

## C02 圆环占比

- 用途：整体明确的完成率或占比。图层：底环 → 进度弧 → 中心数字 → 指标/分母解释。
- 输入：numerator、denominator（或经核实的percent及分母说明）、label、unit、ringWidth、startAngle、duration和主题。
- 步骤：验证分母大于0、数据在适用范围内；计算ratio；数字和弧长共用同一进度；`angle=2π*ratio*p`；最后显示实际分子/分母和剩余量（有意义时）。
- 起点：约0.8–1.2秒描绘，随后停留。多个指标分开标注，不把不相干百分比拼成同一整体。
- 验收：数值与弧长一致，文字居中、环不截断。超额完成率不能静默夹到100%；应显式表示超额或换图。不是占比的数据不强行做圆环。

## T04 斜向色块擦除

- 用途：切换案例或场景，建立清楚边界；不为了每个小切镜都使用。
- 输入：cutTime、direction、angle、coverDuration、revealDuration、wipeColor（映射accent或项目转场色）。
- 步骤：确定底层A/B切点；让超出画幅的斜边色块覆盖A；完全覆盖时换B；继续同方向退出。可用跨切点的一层，也可像demo在相邻MG内衔接，边界必须一致。
- 起点：覆盖与揭示各0.2–0.4秒。根据画幅、倾角计算足够大遮罩，不能照搬1920×1080的固定宽度。
- 验收：检查切点前、完全覆盖、切点后和离场帧；四角无漏光、无残片、无突变。字幕是否在遮罩上方由当前字幕与声音设计决定。

## X04 总结卡片依次入场

- 用途：并列观点、选项、阶段结论。图层：当前画面 → 独立卡片底 → 短句/可选图标。
- 输入：items、layout、stagger、entryOffset、entryScale、holdDuration与主题。
- 步骤：每卡只承载一个要点；按文字宽度和镜头留白排版；从轻微位移/缩放进入，可附小角度归正；按讲解错峰；最后整组停留。
- 起点：通常2–4卡，错峰0.2–0.4秒，整组停留1.5–3秒；不是数量上限或强制节奏。
- 验收：最长文本不溢出、不挡脸/字幕，叠放不盖住字。无演示需求时不额外展示编号、页码或PPT式章号。

## X05-U 下划线展开强调

- 用途：标题、关键词、结论局部强调。它是原X05“原文荧光高亮＋局部放大”的简化派生，demo没有验证完整的截图追踪高亮或局部放大。
- 输入：text、targetRange/targetBox、lineWidth、lineThickness、offset、revealTime、duration、accent。
- 步骤：先确定文字位置与字体；用文字测量或实际容器宽度决定线长；在文字下方从左至右展开；重点出现后保持，避免整屏所有字同时加线。
- 起点：0.2–0.5秒展开，线粗随字号/画幅调整。
- 验收：线与目标文字对应，不压字、不穿过其他行；改字体或文案后重新布局。原文证据高亮应使用原X05配方，保留来源并同步截图与标注坐标。

## 共享实现约束

所有动效由当前帧/时间直接计算，支持向后拖动和随机寻帧；不用计时器或累计上一帧状态。显示值、字体和主要颜色保留可编辑属性。多个独立素材的同一数据需要同步更新，不假定修改其中一个会自动传播。事实数据与演示数据区分；复用时替换演示标记和数值，不能把虚构数据变成事实。

纸艺模式：保留上述顺序与逻辑，将卡片、遮罩等适配为合适纸材；代码可驱动真实裁片，不能用光滑矢量冒充纸艺。信息图模式可使用DOM/CSS/Canvas等清晰几何表现。

## R01 纸面大数字脉冲

- 用途：单个关键人数、金额、次数或覆盖量。
- 图层：浅色纸纹底 → 左上标题、左下来源 → 大数字与单位 → 共享零点长条 → 底部字幕/结论。
- 动作：数字从起值计数到事实终值，长条同步增长；终值先停留，再出现结论。保持单位固定宽度。
- 验收：终值、单位、期间和来源同屏；中间值只表示动画进度，不冒充观测数据。

## R02 纸面圆环百分比

- 用途：有明确整体和分母的百分比。
- 图层：浅色纸纹底 → 底环 → 红/珊瑚进度弧 → 中心数字 → 条件句 → 右上抽象解释锚点。
- 动作：圆环与中心百分比共用 `p`；条件句在弧线完成后进入，最后留完整阅读时间。
- 验收：分母在 facts/shotlist 中可追溯；没有分母时换卡片或条形图，不硬套圆环。

## R03 纸面逐项柱/条对比

- 用途：同单位、同时间口径的数量比较。
- 图层：低对比纸纹 → 标题/期间 → 共享零点 → 按顺序生长的条/柱 → 终值标签。
- 动作：先出第一项，再错峰出第二、第三项；结论晚于比较，不先把“最大/最小”写死。
- 验收：统一尺度、单位和零点；跨险种、跨口径数据不得强行合并成同一比例。

## R04 深色径向关系网络

- 用途：多方对象、责任分工和信息/资金/服务路径。
- 图层：深色背景 → 中心节点 → 外围节点 → 逐条连线/箭头 → 当前节点激活。
- 动作：按“中心对象→一条关系→下一条关系→回到结论”揭示；稳定 ID、颜色和锚点，不突然换图形。
- 验收：箭头方向有口播对应；终态所有节点仍可读；连线不遮字，不用装饰线替代机制。

## R05 固定角落解释锚点

- 用途：连续解释段的定位层，不代替 A-roll。
- 图层合同：来源左下、品牌标识右下无底板、抽象解释锚点避开品牌槽、字幕底部中央；主图表避开四个槽位。
- 动作：锚点先固定，主图表按语义变化；解释锚点可用圆形头像/符号，但不得伪装为真实采访或直接复制参考人物。
- 验收：字幕和主数据不被遮挡；锚点在整段保持同一位置、大小和角色。

## R06 claimRole 网格揭示

- 用途：第三方视频/证据选择逻辑的可视化。
- 输入：`identity / evidence / mechanism / contrast / return` 卡片、claim、source、rights_status、return_cue。
- 动作：一次点亮一个角色；先说当前论点，再出现对应卡片；不因同主题就展示无动作的泛 B-roll。
- 验收：每卡只有一个主任务；reference-only 资源不进入发布时间线；正式素材需具备来源、入出点和权利记录。

## R07 深色大标题章节爆发

- 用途：进入新问题、法律边界或章节冲突。
- 图层：深色背景 → 超大关键词 → 轻微缩放/压暗 → 斜向/硬切进入解释图。
- 动作：标题只承载一个冲突；0.2–0.5秒内完成字卡出现，随后迅速回到事实/关系图，不把字卡拉成长静帧。
- 验收：标题与下一句口播相近；不使用参考视频的人物、Logo、字体包装或原片画面。
