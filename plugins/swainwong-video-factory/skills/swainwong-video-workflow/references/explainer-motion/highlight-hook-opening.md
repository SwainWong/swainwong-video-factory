# H01 爆点预告式开头

可选的完整开头模式：**正文分段主题 → 提取一个或多个爆点 → 编排短口播预告 → 每个爆点用大文字＋前景主体分层动画呈现 → 收拢主题进入正文**。H01 是叙事编排方式，视觉优先复用已有 [D01 主体遮挡大标题](foreground-depth-title.md)及其[字体与动画接口](foreground-depth-title-interface.md)，不是新建的渲染器或已完成的平台模板。

## 何时选用

用户点名“爆点预告式开头／H01／像这次 YouTube 的开头”时采用；否则在脚本方案阶段作为可选项，与事件直入、问题开场等方案一起按内容判断。将选择及理由写进本期脚本方案；用户已指定就直接沿用，不重复确认。可只用一个有力爆点，不要求每个正文段落都入选，也不默认每条视频采用。

适合有若干清楚段落、可兑现的强结果、反差、关键数字或人物关系的解说。单线故事可抽同一核心矛盾的递进爆点；需要铺垫才成立的结论、敏感语境或不适合预先揭底的故事，可保留别的开头。固定的是提炼与呈现逻辑，不固定 18 秒、爆点数、黄字、球迷梗、作者介绍或点赞请求。

## 从正文提炼口播

1. 先有完整正文及段落主题；逐段列出最值得观众追问的结果、反差、数字、关系或转折。每个候选回指正文 `section_id/sentence_ids/claim_ids`，写明正文将在何处解释或兑现。
2. 挑选一个或多个最强候选，去掉重复意思和脱离上下文的噱头。开头可以重排正文看点，不能篡改因果或编造冲突。不要把所有章节标题按顺序念一遍。
3. 改写成可朗读的短句：交代必要主体，再给结果／反差，保留值得看正文的原因或过程。可以透露结果，不把悬念一律写成问句；不能将推测、条件或局部统计改成确定事实。
4. 将短句中的核心信息提炼成大字标题；它与口播共同表达同一个爆点，不必逐字复述整句。人名、数字、年份、比较口径及否定关系不得失真；缩写不能丢掉关键限定。
5. 排成有变化的预告，最强且最易理解的先出，末尾用一句收拢全片主题并接入正文。作者介绍、Logo 动画和互动口播按本期需求决定，不自动复制案例后半段。
6. 使用实测口播给每个爆点安排入场、强调、稳定阅读和退出；纳入全片时长预算。读不完就减字、减爆点或调整预算，不能加速硬塞到 18 秒。

承诺表复用[叙事合同](../storyboard-contract.md)；正文改版、事实更新或某段删除时，同步重核预告及对应大字。预告不是正文证据替代品。

## 每个爆点的画面固定骨架

从后到前：**背景／环境 → 大文字 → 可辨识的前景主体 → 必要的关系/判断图标 → 全片字幕与品牌层**。主体可以是人物、产品、建筑或其他语义对象，不能只有通用大字而没有对应主体。标题被主体自然遮挡，但必须在主构图中保留完整短语可辨的稳定阅读窗口；“阅读窗口”指时间区间，不是另做一套顶部小字版式。具体构图与曲线基线规则见 [D01](foreground-depth-title.md#构图饱满度与标题基线)。

- 沿用本片 CI、字体资产和现有 D01 效果。D01 是视觉实现，H01 是整段叙事：不要把每个预告爆点伪报为新的正文“章节”。
- 先定爆点的语义落点，再定动作：主体建立 → 数字/对象揭示 → 结果/判断强调 → 稳定阅读 → 切到下一爆点。只使用该句需要的节点，允许主体和标题错时进入。
- 同句多个重点可依次揭示：数字先到，结果后到；对象先出现，否定标记再覆盖；关系建立后再给转折。每个大字标题保存完整 canonical 文本，通过已支持的 cue、遮罩或独立的语义标题单元实现次序；不能按人物位置拆字、删字或冒称已有接口支持任意组合动画。
- 快速入场后要留阅读时间；回弹、运动模糊、缩放和位移按语气选用，不能全程抖动。主体朝向、左右关系、文字层级和揭示顺序应随爆点变化。
- D01 的同源背景与遮罩必须同步；独立抠图叠到另一环境的拼贴由合成层承载，单列资产来源，不能伪称 D01 compositor 已自动分割、跨源合成或同步视频。
- 大字是重点层，字幕是口播层。优先使用已锁定字幕槽，调整主体、标题和时序解决冲突，不能照抄参考片黄字幕而覆盖本片规范。
- 按[动画音效合同](../animation-sound-design.md)登记动作组与对应 SFX，⑥负责动画及 SFX，⑫负责跨镜 BGM，⑦组装。多个字的连续揭示不必逐字响；原参考片未实际听审，不能声称复刻其音效或节拍。

## 稳定阅读与主题切换

- 标题入场后保持选定的主构图与基线，直到有语义目的的新动作或本场退出。不为“补一个完整阅读态”在同一爆点末尾额外淡出、拉平、缩小、移到顶部再淡入；这会制造一次无信息的闪换。若用户明确选择有语义的形变／二次揭示，可单独设计，不把本规则扩大成禁止所有标题动画。
- 可读性在主态中解决：调整标题长度、字号、路径跨度／弧度、主体构图与重叠量、停留时长。优先保留大字的突出程度和前后关系，不能用临近切镜的一闪补救主态难读；也不能靠删字或为每个字绕开主体来解决。
- 为每个 A→B 交界单独写清出场组、入场组、方向、区间和固定包装。可选整场推移、切镜或其他适合叙事的转场；纸面／标题／前景的共同场景关系在转场中应保持，不让旧标题独立残留或先闪退再整场退出。确有语义目的的错时动作须写明原因。
- 使用整场推移时，由共同场景容器承载背景、标题、前景；字幕、导航、Logo 等全片固定层留在容器外，由全片时间线驱动。若场景退出由容器负责，避免再叠一个标题独立淡出；原生工程与导出使用同一套时间函数／合成逻辑并验证边界，不能只修预览。
- 接入下一主题不等于其所有文字必须立刻出现。按口播关键词首次揭示的延迟可以保留；区分“第一次有意义地出现”和“已出现后无意义换版”。转场本身也不自动触发新 SFX，沿用动作组合同核对实际声锚。
- 最后一个爆点与正文的连接也需检查。正文既有入场可以保留；交付诊断样片时带上足以观察正文接入的后续片段，不只导出到开头末帧。这里不固定样片为 16 秒。

## 同一开头的有限包装复用

选用 H01 即允许在**同一段开头预告内的多个爆点**共享“大字在后、主体在前”的 D01 层级、字体风格及基础动画代码。按 `packaging_role=opening_hook, opening_mode=H01, hook_id` 登记，正文章节仍用自己的章节身份。

每个爆点须有不同主题信息、与之匹配的主体呈现和明确阅读窗口；变化应服务语义，不机械复制整张海报只换文字。此处共享包装无需为了“新效果”强造另一个图表。该例外只放宽 H01 内的包装复用，**不允许重复第三方原片／原图、证据截图、完整成片镜头或一般数据图**。开头及正文共用同一事实可以；素材仍遵守[同源唯一性合同](../visual-uniqueness.md)，另行分配不同原始素材。不能将预告直接剪成正文原镜头重播，也不授予纯素材时长、覆盖率或机器门禁豁免。

## 最小交接记录

写入本期脚本／shotlist 或项目内 `opening-hooks.md`，不写入插件运行目录。这些是编导交接字段，不冒称状态机已新增 JSON 字段校验。

| 字段 | 内容 |
|---|---|
| opening_mode / selection_reason | H01；本期采用的理由或用户指定 |
| hook_id / section_id / sentence_ids / claim_ids | 爆点与正文、事实的对应关系 |
| promise_id / payoff_scenes | 承诺内容与正文兑现位置 |
| spoken_hook / display_title | 开头口播与对应大字；保留事实限定 |
| subject / origin_ids / asset_roles | 主体、原始素材、背景/前景/证据或示意身份 |
| packaging_role / recipe_id | opening_hook；使用 D01 时写 D01，改编另记实际实现 |
| action_beats / narration_cues | 每个关键词对应的动作、先后顺序及实测口播时点 |
| entry / emphasis / readable_hold / exit | 入场、强调、完整阅读与退出区间 |
| title_layout / style_tokens / implementation | 主基线形态、字体与配色、实际排版实现；曲线适配不冒称通用 D01 API 已支持 |
| transition_to_next | 当前 hook 到下一 hook／正文的场景组、出入时点／方向、固定层与语义延迟 |
| action_groups / sfx_cues / bgm_reference | 动作组、SFX 与全片配乐交接 |
| next_scene_link | 如何从预告接入第一段正文 |

②文案提炼与回指正文，③分镜分配大字/主体/动作，⑤按全片去重分配素材，⑥实现分层动画与 SFX，⑦依实测音频组装；审核沿用既有独立编导、视觉及事实岗位，不另增岗位或生产门槛。

## 检查标准

- 每个爆点都能回到正文原句与证据，正文确实兑现，夸张包装没有改变事实。
- 静音看时能识别主体与重点；开口播后对应同一爆点，没有“字对、主体错”。
- 每个大字都有可读窗口，不因遮挡、超宽、快速切换或字幕碰撞丢失核心含义。
- 动态返修需定位到实际旧版时间区间，查看问题前／中／后及 A→B 边界的最终解码帧；特别检查主态末段是否突然缩小、拉平、上移、透明度归零或出现副本，转场是否有无意空帧、旧标题残留、透明双标题重影、固定包装跟移。仅看每镜中点容易漏掉这些问题。
- 动作次序体现数字、结果、否定或转折；多个爆点共享包装但不机械重复整镜。
- 原素材与一般数据图在预告、正文之间无重复；音频、素材比例和准入仍执行现有门禁。
- 正常速度观看整段预告及其正文衔接，并真实听审口播清晰度、SFX 和 BGM。字段、抽帧、ASR 或解码通过不能代替视听验收。
