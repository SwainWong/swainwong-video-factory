# 口语与表演配置

A-roll范围：本文表演意图可作为真人录制指导；合成、引擎参数、音色档案及TTS试音步骤只适用于实际选定的合成路径。真人已有录制先评估原声take，需要调整时优先补录或按授权剪辑，不为套用参数强制VoiceStudio重配。平台数字人的参数能力须在所选平台验证，不能套用下文VoiceStudio参数；可见讲话画面的任何音频改动同时执行[A-roll合同](a-roll.md)的声画同步复审。

用于口播选项、文案改写、纯音频试版及配音表演。四个维度独立：叠甲决定澄清立场的篇幅，口癖决定说话习惯的密度，语气起伏决定表演意图，局部语速决定少数意群的速度变化。提高一个维度不自动提高另外三个；音色身份另行选择。

## 启动时怎么选

先明确节奏模式，再集中显示独立强度：`节奏：自然起伏｜叠甲：轻｜口癖：轻｜语气起伏：轻｜局部语速：轻`。后四项支持关/轻/中/强，也接受自然语言（如“基本不叠甲，有一点口癖，情绪活泼一点”）。这是skill的对话配置，不声称VoiceStudio已有对应UI滑块。

| 节奏模式 | 实际含义 |
|---|---|
| 匀速清晰（`uniform`） | 统一基准语速，不设计局部加减速；仍保留自然断句、重音和思考留白，不要求每字等长或每句等间隔。 |
| 自然起伏（`natural`） | 以基准语速为主，根据语义在少数完整意群上变速，配合重音和留白。不是逐句交替快慢，也不自动增加叠甲、口癖或结巴。 |

用户已有设置直接沿用。未指定时，社会评论、故事口播采用“自然起伏＋轻度变化”；以逐步操作、精确条款或术语定义为主时采用“匀速清晰”，简述理由并继续，不为普通可逆制作等待批准。不要每轮重问。用户只说“节奏慢一点、留思考时间”时，优先调整信息密度与句段留白，不擅自全片降低讲话速度。

每次启动口播制作、以及改变节奏方案后，**首次合成前主动报出模式**，包括沿用的模式；说明独立强度和1–3个具体快/慢/停位置及原因。匀速模式直接说“保持基准语速，仅在……留白”。尚未有稿时先报模式，标注具体位置后再合成。示例：“本次用自然起伏，局部变速轻量，叠甲和口癖都轻量。已讲过的背景略快带过，新概念保持清楚，核心反问后留一拍；其余正常速度。”这是方案告知，不是新增审批。

模式与配置冲突时：匀速模式的有效`local_rate_intensity`为`off`；自然模式也可关闭局部变速，但须说明“仅调整语气和停顿，不做快慢变速”。引擎无法执行局部变速时，说明实际降级方案，不能把统一速度的结果宣称为已完成快慢变化。纯音频修改无须选择剪辑平台。配置存入当前项目brief或`narration-config.json`，不改全局应用默认，不把本次音色写成永久默认。

```json
{
  "voice_profile_ref": "optional-per-voice-profile",
  "delivery_mode": "natural",
  "caveat_intensity": "light",
  "verbal_habit_intensity": "light",
  "prosody_intensity": "light",
  "local_rate_intensity": "light",
  "baseline_speed": 1.0,
  "verbal_habit_types": ["口头连接", "少量语气词", "偶尔自我修正"]
}
```

## 音色表演个性档案

重复使用一个音色时，先读取[音色表演个性档案](voice-performance-profiles.md)，再决定本次口播配置。档案只提供起始假设，不覆盖用户本次明确要求；本次配置也不自动改写全局档案。

优先沉淀这些可以从样音中观察的特征：

- 句子开头和收尾的习惯、连接词和少量语气词；
- 思考停顿、转折前停顿、结论后的留白；
- 已知背景与新概念的相对速度；
- 叠甲、自我修正、词头重启的频率和语义作用；
- 语气起伏的范围，以及恢复基准语速的位置。

不要把模型的`[sigh]`、`[laughter]`、惊讶类或其他预设表达标记写入通用口播稿。它们最多是经过显式短样验证后的临时控制项；若效果差，应从档案和流程中移除，而不是靠增加标签密度补救。胸腔共鸣、真实换气等声学特征也不能仅凭文案标签声称已经实现。

## 叠甲强度

叠甲是对**一个具体、合理的潜在误解**，用不同说法澄清立场、对象或适用范围，然后回到论点。它可能包含重复两三遍，但不是把同一句复制三次，也不是每个观点前都道歉或加免责声明。不要虚构评论区争论、观众指责或个人经历。

以下为约3分钟口播的起始预算，都是上限参考，不是必须填满的配额：

| 强度 | 写法与频率 |
|---|---|
| 关 | 不额外加防御性话语；事实限定和必要条件仍要保留。 |
| 轻（默认） | 全稿最多1处，通常1–2个短句，说清一个误解就返回主线。 |
| 中 | 1–2处，每处最多2–3个短句；每处对应不同误解。 |
| 强 | 最多2–3处，允许更明显的换说法重申；同一边界澄清后不再反复回头。 |

轻量例：“不是劝人别参保啊，咱聊的是怎么让人一直交得下去。”

中量例：“我不是说社保不重要，养老当然得有保障。也不是劝谁别交。咱聊的是怎么让人一直交得下去。”

如果只是重复已说清楚的态度而没有缩小误读，删掉。用户说“有点啰嗦/叠甲太多”时，优先减少次数与每处长度，而不是把几句免责声明读快了就算改好。更短稿减少预算，更长稿也不要机械按分钟倍增。

## 口癖强度

口癖包括“你想啊、说白了、对吧”等口头连接、少量语气词、偶发词头重启和自我修正。它不等于持续“呃、啊、嗯”，也不等于模拟医学性的口吃。直接、具体、短句的口语表达不依赖口癖：口癖关闭也不能退回公文腔。

| 强度 | 约3分钟的起始预算 |
|---|---|
| 关 | 不主动添加口癖或刻意重启，仍保持口语句式。 |
| 轻（默认） | 约2–4个有作用的位置；词头重启/自我修正最多1处，可为0。 |
| 中 | 约4–7处；重启/自我修正最多2处，避免集中在相邻句。 |
| 强 | 约7–10处；重启/自我修正最多3处，不能妨碍理解或盖过观点。 |

频率是编辑预算，不强迫凑数。叠甲中的“啊”等同样占口癖预算；不因同时打开两项而双倍投放。可选指定偏好/禁用词及是否允许重启，用户没要求时不增加必答问题。幽默优先来自内容观察、反差和临时补充，不靠假笑音效或更多口癖。不要未经要求绑定真实人物的标志性口癖。

## 语气与局部语速

| 强度 | 语气起伏 | 局部语速变化 |
|---|---|---|
| 关 | 克制陈述，仍尊重问句和重音 | 统一基准速度，自然停顿不取消 |
| 轻（默认） | 少数反问、补充或包袱有轻微反应 | 1–2个完整意群，基准的约0.95–1.10倍 |
| 中 | 有清晰的惊讶、认真、调侃转换 | 少数关键意群约0.90–1.18倍，随后恢复基准 |
| 强 | 有明确戏剧起伏，但不持续吼叫或搞怪 | 个别表达可到约0.85–1.25倍，需试听确认清晰与音色连续 |

这些是制作起点与意图，不是引擎能力保证或统一的参数范围。实际控制以当前引擎为准；默认轻度局部变化只用于确有意义且路径已验证的位置，没有适合的位置可不用。

叠甲不必自动等于“惊讶”。常见表演是先轻快澄清，短停，再认真落观点；惊讶更适合反问或反差处。先明确目的再选语气，不能每段照抄同一种表演。

## 哪些地方快、慢、停

以下是创作判断规则，不是所有真人都遵循的固定公式。判断优先级：**意思准确、听得懂 → 观众处理信息的时间 → 表演起伏**。先看这一句的作用及新增信息，再决定速度；没有明确理由就保持基准。读得慢和讲完后停一下是两种手段，不应混用。

| 句子的作用 | 优先处理 | 边界 |
|---|---|---|
| 普通叙述、连接主线 | 基准语速，自然断句 | 给起伏提供稳定参照，不每句都设计变化。 |
| 已讲过的背景、熟悉的列举、短插话 | 可略快带过，主线回来即恢复 | 第一次出现的名词、数字或条件不是“背景”就能快读。 |
| 叠甲、顺口澄清、自我修正 | 简短已知立场可轻快；落回核心观点前短停 | 新增边界、否定、例外要清楚，必要时恢复或略慢；啰嗦先删稿，不能靠加速掩盖。 |
| 新概念、关键数字、复杂因果或适用条件 | 分成易懂的意群，基准或略慢；信息完整后留消化时间 | 不拉长每个字；术语、单位、否定词和数字不能切断或吞掉。 |
| 转折、反问、信息反差 | 转折前或问题后留一拍；关键词清楚落下 | 惊讶可以是短停和重音，不必突然变快；不要每个问号都长停。 |
| 幽默补充、包袱 | 铺垫流畅，包袱清楚，之后给反应空间 | 不把笑点抢读过去，不强加笑声或每段套同一节拍。 |
| 核心判断、结论、需要观众思考处 | 关键词稳住，句末留白；必要时略慢 | 一次落点就够，不把所有结尾都拖成长音或反复强调。 |

局部情绪不与速度一一绑定：激动也能短暂停住，认真也不必整段低速。让观众听出说话者在补充、犹豫、澄清或落观点，比单纯加速减速更重要。按信息密度、字幕阅读和画面理解需要决定留白；句间与段间留白可以不同，不每句固定补同样时长的静音。总时长不足先删重复信息，保留关键思考时间，不能全片提速硬塞。

先在文案上圈出少数有理由的位置：`句子作用/新增信息 → 表演目的 → 目标语气与重音 → 相对速度 → 停顿及理由 → 恢复基准的位置 → 实际引擎参数/方法`。不变速的句子可共用默认设置。示意：“[略快]这个背景前面说过了。[恢复基准]但这里有个区别。[短停，关键词稳住]能找到人，不等于人能一直交下去。[留思考时间]”。这是单处对比的示例，不是每段套用的模板；标注不进入实际朗读或字幕。

以完整意群或自然句界生成和连接，保持同一音色参考、相同基础采样和一致响度；不逐词切开、不把所有句子轮流加减速。句内只需一个词重读时优先用已核实的原生表达能力或改句式，不能为这个词生硬拼接。倍速区间沿用上表，按试听收敛；不把请求的1.1倍当作实际语速恰好提高10%的证明。

## VoiceStudio能力核验与执行

先查本地版本、活动引擎、具体入口的字段与转发路径，再查官方说明。字段存在、请求成功、实际听感达到目标是三个不同层级。引擎列表中的`supports_emotion`可能只表示特定分级情绪参数，不能凭一个false推断所有表达能力都没有。

以2026-10-15本地VoiceStudio 0.5.6 / OmniVoice核验为例（以后须重新核验）：

- `speed`作用于一次生成/一个条目，不是句内时间轴控制器；有`duration`时它可能覆盖`speed`。只让一句加速，可将少数完整意群分别用原生速度参数生成，再连接，其他意群仍用基准值。实测长度不必精确等于算术倍速。
- 本地OmniVoice解析器及[官方说明](https://github.com/k2-fsa/OmniVoice#non-verbal--pronunciation-control)支持`[surprise-ah]`、`[surprise-oh]`、`[sigh]`等非语言声音标记。这主要生成惊讶声、叹息等，不等于后面整句话变成可控强度的惊讶表演。先少量短样测试；不得把未验证的`[angry]`、`[sad]`或SSML标签直接当有效参数。
- OmniVoice的`instruct`是有限的[声线属性](https://github.com/k2-fsa/OmniVoice/blob/master/docs/voice-design.md)，不能把自由文本“这里震惊、下一句认真”当通用导演指令。不要为调整情绪擅改已选人物身份、音高或音色档案。
- VoiceStudio可选的[IndexTTS](https://github.com/debpalash/VoiceStudio/blob/main/docs/engines/indextts.md)有情绪参考、向量及文本情绪控制，但“可选支持”不等于本机已装好，也不保证任一API入口都转发这些字段。未就绪时明确说明；本次核验不安装、不切换全局引擎。另换引擎仍要验证同一参考的音色连续性、中文读音与资源需求。

稳定的局部语速可单独交付；语气未达标时如实写“意图已标注/短样待听”，不要把单纯变快、变响或加一个“啊”叫作完整情绪表演。必要后期保音高变速要记录为后期处理，区别于原生合成；只有对应授权或用户选择该方案时使用。

## 验收与反馈

文案先检查叠甲是否针对具体误解、是否过预算、口癖是否每次有作用；再做10–20秒局部诊断，形成30–45秒综合试音。纯音频试验无需重做整片视频或启动无关分镜审核。

节奏验收对照已告知的模式和意群表：每处变速能否解释其语义理由，关键数字/否定/条件是否清楚，主线是否恢复基准，停顿是否留在意思完整的位置。重点听衔接是否像换了一个人、是否因分段丢失上下文语气、是否出现无意义等待。若只是“能听出变速”却更刻意，降低变化强度或取消该处。实际只能验证参数/时长时就记录这一层，不能宣称已经验证“更像真人”。

A/B对照应优先使用相同文字、音色参考、种子和响度，只改一个表演维度；测试原生速度时记录两段时长，测试惊讶标签时保留原请求并检查是否误读标签。控制标记不进入观众字幕或最终阅读文案。

ASR可能合并重复词、删语气词，不能据此证明结巴已演出，也不能直接断定TTS漏读。分别记录文案、参数转发、生成成功、技术检查与真实听审的覆盖。用户反馈叠甲啰嗦时降叠甲；口癖刻意时降口癖；声音平时调整表演路径，别再靠堆口癖补救。

## 口播章节标题

口播分段锁定后，为视频章节条提炼每段的实际观点：开头、结尾及中段均必须写简短的语义标题，不使用“开篇／总结”通用标签，不能用“观点1／观点2”等编号代替内容。按[CI章节命名规则](ci-and-media-standard.md#章节标题必须表达口播观点2026-10-19)保存时间段与口播依据；不为配合标题改写已确认的口播结论。

章节标题锁定后，按该段实际口播起止时间分配顶部宽度；全片亮色随播放时间连续累积，边界与口播进入对应章节同步。实现与检查遵循 CI 合同的时间比例规则。
