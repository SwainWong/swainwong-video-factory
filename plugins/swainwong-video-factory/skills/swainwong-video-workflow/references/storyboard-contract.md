# 叙事、动作与声音设计合同

涉及主持A-roll时加载[A-roll合同](a-roll.md)，分镜增加句子ID、take映射、原声/生成音频主时钟、人物槽、B-roll并行时点和安全区。以下第三方纯素材3–5秒及同源唯一性不限制授权主持连续表达与固定人物容器；内容层与第三方引用仍按原规则查重。

## 1. 故事锁定与时间预算

先写一句话主线、观众核心问题、一个主要爆点、情绪走向和结尾回扣。人物生平、节目过程、赛后选择按主线取舍；不要把履历、菜谱和金句平铺成并列清单。幽默不能打断尚未完成的关键操作或抢走结果。真实关系分清：时间先后、编辑呼应、报道支持的因果，不能互相冒充。

选用 [H01 爆点预告式开头](explainer-motion/highlight-hook-opening.md)时，先完成正文，再从分段主题提炼一个或多个爆点，写短口播与大字标题，逐项回指正文兑现位置。以大字＋前景主体分层动画逐次揭示；爆点数和预告时长服从内容及实测音频，不固定为 18 秒。

脚本前置承诺表：

| 字段 | 必须回答 |
|---|---|
| promise_id / 原句 | 向观众提出了什么问题、数量、过程或结论？ |
| payoff_scenes / 答案 | 在哪些镜头兑现，具体展示什么？ |
| evidence_ids | 每个被承诺对象的名称、影像、现场声音分别有何证据？ |
| status | 已闭合／待调研／待用户决定；不能用“结构示意”顶替内容 |

提到五道菜，就列齐五道菜及对应真实画面，四道可简述、一道人物核心菜详述。查不到名称是调研缺口，不是画空盘的理由。非用户强制的承诺可删改原句并重审；用户明确要求的内容只能补证据或请求取舍，不能悄悄缩减。

总时长=独占旁白＋新增停顿＋独占原声/环境声＋无旁白首尾；重叠部分只计一次。先按样音估算，锁音后用实测替换。若超出用户确认范围，优先删重复议论、地点罗列与冗余笑话；仍超时就给取舍选项，不挤掉高潮/原声/证据、不加速硬塞。

## 2. 素材丰富度（启动时选择）

丰富度衡量语义信息、动作状态和来源覆盖，不等于同屏数量或生成次数。以下是纸艺段的策划起点，不强制把实拍原声盖满纸片。

| 档位 | 每个意群的视觉计划 | 适用节奏 |
|---|---|---|
| 简约 | 一个清楚的视觉意思；该有的操作、因果、结果仍完整 | 克制留白、证据和人物原声为主 |
| 中等 | 通常1–2个相关视觉推进；人物状态随叙事改变 | 平衡实拍与纸艺解释 |
| 较多 | 通常2–3个语义推进；组合人物、对象、环境、行动与结果 | 场景与反应更丰富，减少通用道具复用 |
| 最多 | 对每句需纸艺说明的文案规划至少3–4个不同的示意/动作节点，可同镜分层或连续呈现 | 每个节点回答问题；不是每句切四张海报，也不是同时塞四件装饰 |

“最多”遇到1.5秒短句或完整人物原声，不压缩为闪图：合并为完整意群，延长动作镜头或保留原声实拍；分镜写出例外理由并审核，不悄悄降档。任何档位都不能降低动作完整性、事实或承诺闭环标准。

分镜前建立[画面唯一性台账](visual-uniqueness.md)：第三方视频/图片及整镜图表/动画在同一成片内不得二次使用；发现第二次出现就替换，不存在“第三次才检查”或“有意回扣可复用”的通行条款。人物身份与纸艺道具的连续动作状态可保持一致，但不能循环同一整镜表现。固定Logo、字幕、章节导航单列为持续叠加层，不能用这类例外放行主画面重复。背景简洁可以，表达不能空。选用 [H01 爆点预告式开头](explainer-motion/highlight-hook-opening.md)时，同一预告内多个爆点可按其有限包装复用条款执行，不重播正文素材或完整镜头；[D01 主体遮挡章节标题](explainer-motion/foreground-depth-title.md)可按其严格限定在不同真实章节开头、不同原始素材与独立观点下复用章节包装；同源第三方素材和一般整镜图表／动画仍不得二次使用。

## 3. 逐镜合同

每镜必填：`scene_id, script_id, sentence_ids, claim_ids, narrative_role, question, answer, duration_estimated_or_actual, spoken_text_or_original_cue, visual_subject, character_phase, source_ids, fact_source_ids, evidence_overlay_origin_ids, visible_evidence, event_date_scope, semantic_status, source_timecode, framing_crop, assets_and_states, action_beats, sound_plan, subtitle_slot, promise_ids, next_scene_link`。

- `semantic_status` 只能是 `direct_evidence / contextual / illustrative_only / original_explanation / credits`。`direct_evidence` 必须同时绑定 claim、fact source 与观众实际能看到的 `evidence_overlay_origin_ids`，并在 `visible_evidence` 逐项写明 `claim_id → fact_source_id → exact locator/crop → date_scope → on_screen_start/end`；其余状态的 `visible_evidence` 必须为空。示意素材必须保留 `illustrative_only`，不能在下游构建时静默升级成事实证据。事件日期、门店范围、主体和统计口径任一不一致即为 `direct_mismatch`，不得进入生产。同一网页／文件换截图、裁切或高亮仍是同一 evidence origin，不得跨单元重复；要么合并成一次连续证据窗口，要么其他单元降为来源标注／语境素材并使用不同主画面。
- 每项 `direct_evidence` 在 G1 前还必须绑定 capture receipt：最终 URL/文件、实际打开时间、响应状态、支持原文的精确 locator、捕获文件路径和哈希。HTTP 200 但正文为空、当前 404、登录后仍不可见、仅搜索摘要/缓存、只有旧截图而无法回到支持原文，均视为不可生产并返回研究/素材岗替换；不能等到编辑或成片门禁才发现。
- 素材分配必须由句子、主张和事件范围驱动。不得按文件名、素材数组顺序、取模、固定间隔或“每三格一张图”轮转素材；第三方覆盖率和视频占比是结果门槛，不能反过来覆盖语义匹配。

`storyboard=READY` 还必须通过插件内 `storyboard_gate.py` 的确定性重算。机器门禁只接受 canonical `audience_visual_units`，直接读取项目内 capture 文件核对 receipt 哈希，并按锁定简报重算覆盖率、vector 禁令、时间线、credits、同源连续区间、固定 5 秒墙和真实章节边界三点进度探针；不能用项目自定义 validator、自写 `PASS` JSON 或字段声明绕过。门禁通过只说明机械合同成立，不说明画面创意优秀，也不替代独立 G1 视觉审核。

- `action_beats`：帧区间/相对时间、谁对什么做什么、起终位置、接触点、层级遮挡、姿态/形变变化、为什么此变化能表达口播。非动作镜说明新增的事实/反应。
- `sound_plan`：旁白主导／人物原声独占／环境声主导；原声文本或音响内容、源入出点、旁白退回时间、音乐让位与接续。动画先逐项登记 `animation_events`，按故事/对象/动作组成 `action_groups`，再填写 `sfx_cues`；同一连续动画或密集揭示组只选一个短音锚点或一个完整声体，不逐帧触发、不以短音堆成长音。关联事件与组ID、声音角色、唯一触发锚点、素材/包络及不重触发处置；独立新动作与短间隔例外记录边界，保护豁免定位具体区间。按[动画与音效配套合同](animation-sound-design.md)交接：记录动画/SFX责任岗⑥与BGM责任岗⑫，SFX逐事件映射、BGM按全片区间另表规划；动画节奏修改后由⑥重对齐SFX，影响音乐接续时通知⑫及⑦。
- `visual_uniqueness`：记录`origin_id / visual_unit_id / recipe_id / visual_structure / motion_sequence / claim_id / used_interval`，与全片已用内容比较；素材、效果、口播意群一一对应，两个不同意群不能套同一张表或同一整镜动画。字段和核验见[去重合同](visual-uniqueness.md)。
- `next_scene_link`：本镜已回答什么、带到下镜的是什么；不得从失败直接跳到胜利后声称展示了成长。
- `subtitle_slot`：引用项目锁定的底部中央槽；原声和旁白不设不同位置。`framing_crop`同时检查固定左下来源、右下无底板Logo、顶部进度条及字幕包围盒，不能到渲染时临时换槽。
- 每镜有一个主视觉焦点，可以有多个承担功能的辅助层。按“人物—环境—问题—行动—结果”检查所需要素，不能只拿与名词相关的一件道具顶替整句。
- 地理、门店、品牌和关系镜头按[视觉语义](visual-semantics.md)补充对象可辨性、Logo所属对象、连接含义及标签防遮挡；节点名称居中加粗，重要信息在整个运动路径中可读，语义覆盖例外写明理由。顶部进度条绑定段落时间而非逐镜标题；所有章节含开头、结尾均用该段口播观点或核心提问的词或短语命名，记录 `chapter_label`、起止时间与对应原句，不用开篇／总结或观点编号占位；分段宽度按实际时长占比，亮色按全片时间连续推进。
- 第一眼对应测试：拿掉字幕/旁白，编导和观众各说看到了什么；再开口播，能否立即对应对象、阶段和动作？不行就补关键要素、改裁片状态或更换实拍，不先加解释大字。

## 4. 人物状态库与真实参考

为高频主角建`identity_reference, phase, outfit, expression, gaze, torso_hand_pose, prop, entry_state, exit_state, scene_ids, evidence_or_interpretation`表。按脚本覆盖平静讲述、观察、判断、操作、受挫、反思、获胜、赛后工作等实际需要；喜怒哀乐不是四张表情包任务。不同人生阶段要有相应外观与服饰参考，不能把当前肖像机械变年轻当作真实旧照。

真实人物动作参考优先取对应原片；情绪必须符合证据或明确的作者概念表达，不能生成虚假愤怒/崩溃当节目事实。冠军场景锁定本人、实际奖项形制和对应持奖动作，优先整体裁片，保持手与奖项的接触关系；先核实奖项是杯、牌还是其他形制，不预设举杯。纸艺风格本身不是事实来源。

具体人物的场景优先使用其辨识特征，可采用照片纸艺大头形象；不要用通用职业人物加姓名标签弥补身份缺失。每个动作状态同时考虑视线、表情、躯干、手部和持物关系，不把同一立像的位移算作新的表演姿态。概念表达仍须符合人物事实，群体数量/台词不能被误读为真实统计或人物原话。

## 4.1 多裁片过程合同

过程型镜头按“起因/压力→察觉与判断→准备→接触操作→结果与反应”设计，按实际叙事取所需节点，不机械凑满五步。环境稳定；人物、目标、阻碍、道具与结果各有功能，可在同镜中独立活动。施力者与持物需要共同生成时保留接触完整组合，其余层仍可独立编排。

动作表在`action_beats`内补：`actor_id, target_id, state_from/to, contact_or_release_time, anchor, trajectory, occlusion, result, narration_cue`。无接触动作写明不适用；记录何时抓住、何时放开、道具归哪一层持有，避免手中和桌上同时出现同一物件。物体平移、碰撞、飞入要有可读原因，不让餐盘/材料无因自行滑走。

例：表达“需求增加但坚持品质”，队列增长和订单积累承担压力，主角观察、限量手势及认真处理出品承担回应；不能用一个催单者替代“多人排队”。不要求固定人数，也不虚构真实投诉、降质事件或主角台词。缺料则让缺失物、否定标记、判断者、替代物和实际操作构成完整关系，不能以旁边的一口锅代替动作。

分别记录有效姿态/形变数量、位移更新节奏和导出fps；三者不是同一个指标。八张姿态不是通用合格线，12Hz位移不表示每秒12个新姿态，30fps输出也不能补齐语义缺失。按正常速度观看检查中间态、接触连续性、口播重音对应和结果可读性，缺什么补什么；不要通过全片加速或延长静帧掩盖缺口。

## 4.2 动物身体动作

涉及走、跑、跳、飞、攀爬时执行[动物动作可信度审查](animal-motion-review.md)。动作卡明确支撑与发力部位、离开支撑和重新接触时刻、关节姿态及承重恢复。轨迹变化和身体姿态分别设计；整体缩放不是腿部蹬伸。卡通夸张不豁免动力因果，图标/纯装饰运动不机械套动物规则。

## 5. 形变动作：用揉纸作为验收样例

“整纸→纸团”两张切换不叫揉。默认至少6个可辨的实际纸张形变状态，另有施力者；优先生成手与纸的完整组合序列以保证接触。以下是2.6秒、30fps（78帧）的关键状态设计示例，纸片采样节奏需正常速度试看片确定：

| 帧区间 | 手和纸的状态 | 语义与声音 |
|---|---|---|
| 0–11 | 双手持完整计划单，手指接触两侧 | 建立对象和做饭意图，旁白落下 |
| 12–21 | 双手向内施力，纸边弯起，中央仍平 | 开始放弃；第一次纸响 |
| 22–31 | 两角折入，出现大折痕，手遮住接触点 | 受力与形变因果清楚 |
| 32–41 | 纸面收成不规则褶皱团，手掌继续合拢 | 中度压缩，不能直接替换成球 |
| 42–51 | 团块变小变密，残余边角仍在手外 | 第二次挤压与褶皱声 |
| 52–63 | 手指把边角压入，形成最终纸团 | 完成动作，末次纸响 |
| 64–77 | 松手、纸团落定、手离开 | 结果停留及笑点留白，不叠满旁白 |

这些是关键状态，不保证六张图就自然流畅；若预览仍跳跃，生成真实中间形变/接触姿态。位移可试用8–12Hz更新保留手工顿挫，但这不是生成姿态数的要求，也不代替形变；按实际动作和正常速度试看调整。位置移动可以插值，纸张拓扑变化不能靠整张淡入淡出或拉伸伪造。30fps只是输出采样，不是30个有意义状态。

缺料示意同理：先呈现真实缺失的原料＋生成纸艺红叉，再出现人物寻找/判断状态，接实际替代原料和操作，最后给出结果。先核实到底缺什么，不把替代品误标为缺失项。

## 6. 原声与口播表演

先在源视频确认原声是否包含当前事件，不仅看静音画面。每个主要事件检查有无值得独占的现场话语/反应/操作声；没有就说明调研结果，不以统一静音绕过。为代表性事件安排完整短句或完整动作的原声窗口，未被当前简报限制时，常见3–10秒只是起点；当前用户要求纯素材3–5秒且只允许DataMagic叠加例外时，原声窗口也须遵守该上限；不能为1.5–3秒视觉节奏硬截人话。环境声可在旁白前后延续，J/L-cut须保留事实语境与同步。

旁白把答案交给原声时，候选窗口必须实际包含答案，预告/猜测不算揭示。字幕只用于定位，不是音画精剪点；制作、品评和下一道内容分别锁定，不能凭宽窗口推断所有反应都存在。后采回顾不冒称灶台同期协调；不同采访不借口型，转述另一份文字来源时明确切开署名和声音。新增采访须有新增信息的职责，不因找到素材便重复已结束的高潮或倒退叙事。

口播表逐句记录：叙述目的、语气、重音词、句内/句尾停顿、承接原声的入退点、实际使用的TTS参数/分句策略。生成前明示“匀速清晰”或“自然起伏”；叠甲、口癖、语气和局部语速使用[独立强度配置与语义节奏规则](speech-style.md)，点状变速还要标明语义理由及恢复基准的位置。搞怪靠铺垫—留拍—包袱—反应，思考可用正常语速讲完后留白，必要时略慢，不靠变声器整片变调。参数能力不支持情绪指令时，不虚称支持；用可验证手段做短样音，真实试听不达标就继续调整或请求用户试听，不能把表演稿通过当音频通过。

听感否决分别记录“音色相似度”“节奏/重音/停顿”“文字/发音”。节奏问题先保留同档案和统一基准参数，比较完整意群及口语句式；后期停顿只用于明确语义/原声进退，不用每句固定补静音。10–20秒A/B仅诊断单个问题，不取代30–45秒综合表演试音或全片听审；尚未获准的试音不得流入生产时间线。

原声与旁白切换需做统一感知响度与底噪衔接，但不抹平全部锅声动态。人物说话时旁白退出、BGM下降；环境声主导时可降低音乐；用户要求贯穿BGM时不得抽掉，否则须有明确声音设计依据。实拍原声、口播、BGM、拟物音效分别保留分轨和使用区间。
