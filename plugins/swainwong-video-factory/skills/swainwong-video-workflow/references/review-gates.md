# 独立审核门槛

涉及A-roll时，三个独立审核角色还必须执行[A-roll合同](a-roll.md)的G1设计、G2 First Full Cut 实际整片、G3成片关口。以下素材重复/5秒规则不适用于授权主持有效句段及人物槽复用；口型循环、冻结讲话、失同步及遮挡仍须阻断。主Agent只收集与派发报告，不代替实际生产或独立签发PASS。

## 送审材料与角色

脚本与全片分镜完整后送同一版本：用户简报、叙事承诺表、事实/原始来源、逐镜合同、动作状态表、声音时间轴、素材覆盖台账、每项 direct_evidence 的 capture receipt（实际打开时间、响应状态、精确 locator、捕获文件及哈希）和[画面唯一性台账](visual-uniqueness.md)。每位Agent独立形成意见，首次判断不看其他评审结论、不提供暗示通过的答案。作者自检不算独立审核。来源当前 404、空壳、登录后不可见、只剩搜索摘要/缓存或无法回到支持原文时，G1 必须 REVISE；旧截图存在不能替代当前可复核来源。

| 独立角色 | 必查内容 | 必须给出的结果 |
|---|---|---|
| 专业视频编导 | 主线/爆点/人物弧、首尾回扣、工序/动作因果、原声窗口、节奏、制作可执行性 | 场景/帧区间/原句、问题为什么成立、具体补镜/删改/动作建议 |
| 专职观众画面语义 | 每镜实际画面能否说明对象、关系、动作和结论；与口播对应；品牌归属、遮挡、实体可辨性；兼顾好奇心兑现、重复、跳跃与收尾 | 逐镜写先看到什么、理解了什么、具体误读、缺少什么及修复；不依据源码意图猜观众能懂 |
| 事实检查 | 人物、菜品、奖杯、日期、比赛阶段、视频场合、引用上下文、数字与因果；正文和画面一起查 | 每项claim/scene对应来源和入出点、拍摄/事件/发布日期、冲突与未知，不把文字可信推导为画面可信 |

资料来源的转载不算独立证据。资料年代注释不能治愈赛后口播配十年前实拍的语境错误。需要当前现场却无法找到：继续调查，采用实际赛后采访可核实的原文/影像，或给用户明确缺口；不能用旧素材加小字充数。

观众画面语义为默认专职子Agent，替换旧“综艺观众”岗位并保留其叙事理解职责；不额外强制增加第四个岗位。逐镜按[对象、关系与观众理解](visual-semantics.md)检查，先看真实画面再读实现说明。只收到局部截图时可开展局部复盘，标明覆盖，不能据此判定动态全片；上下镜可能已解释的信息应在连续片段复核后定性。

动物身体动作增查[动物动作可信度审查](animal-motion-review.md)的五项门槛。独立审核必须检查实际成片正常速度的完整动作；只能看静帧或数值时保持PARTIAL，不因“未发现Important”自动放行。静坐造型整体升空、无支撑发力或无落地承重属于Important。已知失败可据明确帧证据退回；报告完整性可用 `scripts/check_animal_motion_review.py` 检查，但程序不判断自然度。

## 输出合同

动画按[动画与音效配套合同](animation-sound-design.md)逐事件核对SFX映射、可编辑交接和最终混音。检查事件→动作组→声音的完整处置；同动画多帧反复触发、以短音拼成长音、计时器到点自动重响、独立动作组无理由漏配、明显错位或遮住关键信息列为Important。同组一个短锚点是允许设计，组内不重触发不算漏配，不能因声能未覆盖全过程要求补声；音频能力不可用时保留待听核项，不以cue表、波形或播放成功替代实际听审。

每份报告包含：角色/Agent标识、输入版本或哈希、实际读/看/听范围、未覆盖范围、逐条问题（严重度、位置、证据、修复）、`PASS / REVISE / PARTIAL / UNAVAILABLE`。只有完整覆盖相应阶段且Critical/Important关闭才可PASS。静帧看过不是动态看过，ASR不是听过，脚本可行不是成片成功。

Critical：事实/人物/阶段严重错配、伪造事实证据、关键承诺缺失、未授权替换本人声音、文件损坏、第三方视频/图片二次使用、DataMagic或其他相同整镜表格/动画效果重复套用。画面重复是根本性问题，第二次即阻断该阶段通过，不降为Minor或用占比达标抵消。[D01 主体遮挡章节标题](explainer-motion/foreground-depth-title.md)按其限定范围可在不同真实章节开头、不同原始素材与独立观点下复用章节包装；第三方同源素材及一般整镜图表／动画重复仍按上述 Critical 判定。 选用 [H01 爆点预告式开头](explainer-motion/highlight-hook-opening.md)时，同一段开头内多个爆点可按其限定范围共享 D01 层级包装，以 opening_hook 登记，不虚构章节。该例外只针对开头包装；第三方原片／原图、证据截图及一般整镜图表／动画的重复仍按 Critical 判定。

Important：纯素材超过5秒且无实质DataMagic叠加、缺少贯穿BGM或交付/预览音轨丢失、CI混乱、Logo黑底板回归、原平台水印漏糊、纸艺动作省略因果、手物接触断裂/重复物件/无因位移、人物难辨、长时间无语义推进的静态画面、无原声且无说明、语气持续平直/过快、字幕遮挡或违背固定槽、来源/Logo漂移、裁片残边或配准跳动、主素材不满屏、矢量信息意外遮挡、品牌Logo归属不明、实体标签难辨、地域/关系结论只有无关实景、进度条与内容错段、来源漏记、缺乏主线或爆点。

Minor：不影响理解的局部配色、边距与细微动作问题。

不能用总分平均掩盖某一Critical。修复人记录变更，原角色复核受影响范围；大幅改脚本则三个角色重新审核。旧报告保留，禁止覆盖成“原本就通过”。

## 生产与成片关口

1. 初始条件先按[制作简报合同](production-brief.md)由人类确认并通过入口校验，才能派资料研究、动画匹配和执行；必要平台档案待核验不算锁定。研究后再核关键事实和来源覆盖，不能把初始方向锁定当作事实通过。
2. 先完成可生产脚本：正文结构、句子 ID、claim 映射、时长与承诺回收齐备；编导和事实 G1 关闭 Critical／Important。粗分镜只需足以让每个句子进入时间线，不要求最终素材和动画全部到位。
3. 最低完整播放条件成立后立即做目标时长 First Full Cut；正式或临时画面覆盖每个句子，所有缺口写入 placeholder manifest。高风险技术小样可并行，但不阻塞整片粗剪。
4. G2 在完整粗剪上定位结构、事实、画面任务和节奏问题；随后在同一整片时间线上横向替换素材、生成配音、完成动画/SFX、BGM与混音。重大脚本或事实改变只让受影响依赖失效。
5. 完整候选实际导出后，每个实际镜头至少按起点／中点／终点核对去重台账与最终画面；每个镜头的可辨状态均须覆盖，不能只用固定每3秒抽样漏掉短镜重复、0.3 秒闪卡或瞬时错位。先运行 `swainwong.final-visual-gate.v2`，再由三份 G3 独立报告绑定候选哈希；连续视觉审片和真实听审覆盖全片，另做技术全解码/ffprobe/字幕时间/音轨/响度等检查。
6. 交付状态分开：脚本审核、First Full Cut 完整性、素材核验、成片技术验收、连续视觉审片、实际听审、用户音色确认。任一不可用即写清，不能一句“全部通过”。

完整成片候选须执行[候选片视听准入门禁](candidate-av-gate.md)。独立审核者对素材政策、单一字幕、口播节奏、动画SFX可辨和BGM可闻分别签结论；G3 视觉另查章节标签、品牌叠加、素材观感和短镜可读，G3 事实另查来源语义、事件日期范围和主张—画面对齐；机器门禁核章节导航、来源质量、同源唯一性、可读页、品牌叠加层及逐单元语义合同完整度。三份 G3 未绑定同一候选哈希或任一项未通过，不得生成 `owner-review-ready`。用户对实际候选明确否决时，该哈希立即退回 `REVISE`，此前零问题摘要或测试 override 失效。First Full Cut 只证明完整粗剪存在，不继承或预支这些 PASS。

每次 First Full Cut、完整候选和返修渲染后均按[视频反馈合同](video-feedback.md)提供加载实际输出的审片页面：内部门禁前只能是 `--audience internal` 诊断页，`owner-review-ready` 后才可用 `--audience owner` 提交用户验收。逐帧/片段评论绑定视频哈希；返修后关联原评论复核，保留旧版结论。页面使用记录、评论数量、评论关闭或浏览器播放进度不能充当连续观看/真实听审证据，也不自动批准成片。长期偏好候选由相关专业岗提炼后交独立审核，保持用户确认边界。

仅讨论或验证单项反馈时可先做3–5秒动作小样/独立版式图，验收只覆盖所测试的动作、身份、布局或声音；这不是所有镜头的时长规定，也不触发完整影片重制。需要用户确认的风格/版式先给小样，已确认的不重复设关；短样通过不等于全片或综合表演试音通过。

成片版式检查必须读取最终导出：单/双行字幕底框位置、原声与旁白同槽、无烧录字幕重影、左下来源、右下无底板Logo实际alpha宽度和不透明度、运动极值无遮挡。不同平台/字体渲染器分别测量实际视觉结果，不盲抄字号数值；编辑器默认字幕与烧录结果不同时记录差异。连续审片查动作与接触，静帧查边界，技术解码查文件，真实听审查表现；每项各留证据和未覆盖范围。

双平台共享锁定内容但工程/渲染/成片验收独立。各制作Agent只修改自己的平台目录；主Agent管理内容一致性和跨平台反馈。不可因一个平台通过就给另一平台盖章。

## 防止旧问题回归

| 易出现的理由 | 正确处理 |
|---|---|
| “渲染已花很久，先交付再补过程” | 保留旧版；缺的关键过程先补设计和证据，不能牺牲承诺 |
| “素材只有两张，旋转四肢也能动” | 人物完整姿态＋接触/形变状态，不把位移当表演 |
| “有40个片段，来源足够丰富” | 同源切片不算新素材；第三方原始视频每片仅用一个连续选段，图片每张只用一次 |
| “比例达到1:1，重复图片也可以” | 占比与唯一性分别验收；重复使用仍是Critical |
| “换了标题、数据、颜色或模板ID，就是新动画” | 比较整镜布局、图表结构和动作顺序；同一效果换皮仍不通过 |
| “结尾回扣，可以再放一次” | 用新的素材和视觉表达回扣观点，不重放已用画面 |
| “只查到最后一道，就用空盘代表其他四道” | 承诺未闭合，不进入批量制作；继续调研或明确请求取舍 |
| “都3–5秒所以没有PPT感” | 看动作和新增信息，短静态幻灯片仍是幻灯片 |
| “统一speed加mood就是情绪口播” | 核实实际发送参数并真实试听，不能用字段名证明表演 |
| “加旧影像标注就可以当当前事件” | 阶段语境同样要匹配，旧资料只放明确历史/回溯段 |
| “已有8张姿态、30fps导出，所以动画合格” | 状态数、位移节奏、输出fps分别登记，实际速度检查过程及接触 |
| “底部有烧录字幕，把我们的字幕放顶部” | 固定槽不漂移，换干净源/镜头或安全处理源字幕，不遮证据 |
| “10个API名称就是10种免费声音” | 核实独立音色、就绪状态和免费条件；别名去重，模板另列 |
| “预览字号相同，导出肯定相同” | 检查最终交付的可见字高、黑底框与Logo alpha包围盒 |

以上是失败模式检查，不得强迫用户无必要地逐阶段重复批准；简报/创意已获所需确认且三审通过后继续已授权工作。新付费、发布、缺失用户选择或无法补足的关键事实仍需单独处理。

用户要求90分以上时，三位独立Agent按实际观察范围诚实评分；各角色相应阶段均须大于90且Critical/Important关闭，不能用平均分、加权总分或缩小验收范围掩盖未验证的视听环节。
